# Приёмка M14 — исправления Windows по живой проверке 0.8.0, релиз 0.8.1 (2026-11-11)

- Спецификация: [M14-windows-fixes.md](../planning/M14-windows-fixes.md); scope
  `m14-windows-fixes`, режим `sequential`.
- Причина: живая проверка 0.8.0 на Windows 11 ([M13](M13-acceptance.md), находки 1–8) и два
  замечания пользователя: «Можно ли Workflow Kit открывать не в Edge, а в Chrome?» и «при
  выборе диска папки… присутствует только диск C. А нужно иметь выбор любого диска.»
- Пользователь, 2026-11-11: «Поэтому, выполняя работу последовательно, собери, пожалуйста,
  новый релиз. И можешь сразу принять этот скоп и залить новый релиз на GitHub.»
- Что сделано:
  - T001 `997a972` — `git` без консольного окна (`windowsHide`), находка 8.
  - T002 `5866365` — панель на Windows в Chrome, затем Edge; подсказка про `wfk` после
    установки (Windows Terminal закрыть целиком), находка 7.
  - T003 `bde7122` — выключенный UAC: `daemon-elevated`, проверка `elevation`, вердикт
    `broken`; «Работает» только при работающем демоне и `ssh.exe` старше 15 с (находки 1, 2).
  - T004 `c4e8e0d` — карточка «Общий доступ к чатам» (находки 3–6).
  - T005 `f245fe4` — папка проектов на любом локальном диске (`allowedRoots`,
    `resolveInsideRoots`, переключатель корней).
  - T006 `2137a60` — README и руководство; DOCS `7d5016d` — OVERVIEW, спецификация, дайджест.
  - T007 — выпуск 0.8.1 и исправление, найденное его живой проверкой (ниже).

## Проверки релиза

- Локально (macOS): `npm test` — 639 тестов, 638 прошли, 1 пропущен (не для macOS); проверка
  типов и `check:platforms` — ok; `node bin/wfk.mjs install` (обновление с 0.8.0) и
  `wfk doctor --installed` — «всё в порядке», служба 0.8.1, общий доступ ChatGPT — «Работает».
- Живая проверка выбора папки на Mac: `GET /api/folders` сначала вернул среди корней скрытый
  `/Volumes/.timemachine` и служебный `/Volumes/com.apple.TimeMachine.localsnapshots`.
  Исправлено в T007 (Kit не даёт открыть новый раунд во время выпуска, поэтому задача выпуска
  расширена этим исправлением): скрытые точки монтирования и тома `com.apple.*` пропускаются.
  После переустановки корни — «Домой», Backup, Time Machine; `/Volumes/Backup` открывается,
  у корня `parent` = `null`; `/private/tmp` — `outside-roots`.
- Панель (macOS, «Настройки» → «Изменить папку для проектов»): переключатель «Домой»,
  «Backup», «Time Machine»; на корне тома кнопка «Сделать папкой для проектов» доступна, на
  домашней папке — нет. Папка проектов пользователя не менялась.
- Причина мелькающих окон на Windows подтверждена пользователем до выпуска: после остановки
  службы Kit окна перестали появляться.
- CI ветки `ci/m14-windows-fixes` — записывается после запуска.
