# Кластер: backend-core / http-api

## Назначение

HTTP-слой бэкенда: сервер на всех интерфейсах, фильтр доступа по D8
(только loopback и Tailscale), реестр маршрутов API, реестр разделов
`/api/state`, раздача статических файлов панели.

## Модули

| Модуль | Обязанность |
| --- | --- |
| [http-server](modules/http-server/module.md) | HTTP, фильтр доступа, реестр маршрутов и разделов состояния, раздача панели |

## Границы

- Не содержит предметных маршрутов: проекты, провайдеры и операции
  регистрируют свои маршруты в реестре при сборке приложения (`cli`).
- Не читает диск, кроме раздачи файлов из зарегистрированных каталогов.
- Секреты в URL не кладутся; ответы API — JSON с `Cache-Control: no-store`.
