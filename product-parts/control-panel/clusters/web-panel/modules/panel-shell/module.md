# Модуль: panel-shell

Часть `control-panel`, кластер `web-panel`. Алиас импорта: `#panel-shell`.

## Назначение

Каркас веб-панели: страница с шапкой (название, версия, ОС, состояние
связи), опрос `GET /api/state` раз в 3 с, реестр карточек, карточки
«Система», «Проекты» (список, создание, открытие папки выбором из списка)
и «Структура Kit» (статус и установка по проектам). Файлы панели — статические ES-модули без сборки (D3), лежат в
`src/` и отдаются сервером в корне сайта.

## Публичный интерфейс для бэкенда (`src/index.ts`)

- `PANEL_ASSETS_DIR` — абсолютный путь к `src/` модуля.
- `panelShellMount() → { prefix: '/', dir }` — монтирование для
  `http-server`.
- `STATE_POLL_MS` — 3000.

## Файлы панели

| Файл | Содержание |
| --- | --- |
| `index.html` | разметка: шапка (`#meta-version`, `#meta-os`, `#link-status`), контейнер карточек `#cards`; стили панели и расширений (`provider-cards/provider-cards.css`); без встроенных скриптов и стилей (CSP) |
| `styles.css` | системный шрифт, светлая и тёмная тема (`prefers-color-scheme`), адаптивная сетка карточек (Mac, iPad, узкие экраны), safe-area |
| `controls.css` | кнопки и поля (не ниже 44 px, шрифт поля 16 px — iPad не масштабирует страницу), сообщения, карточка «Проекты», выбор папки |
| `app.js` | опрос `/api/state` (следующий запрос — через 3 с после ответа, таймаут 8 с, сразу при возврате на вкладку), шапка, отрисовка карточек и групп (секции держатся в порядке карточек, исчезнувшие удаляются); загрузка расширений `PANEL_EXTENSIONS` (сейчас `/provider-cards/provider-cards.js`) до первого опроса: `install(shell)` с помощниками `registerCard`, `registerCardGroup`, `requestRefresh`, `api`, `ApiError`, `dom` (`h`, `facts`, `pill`, `code`, `notice`, `plainInput`); упавшее расширение становится карточкой с ошибкой |
| `cards.js` | реестр карточек: `registerCard({ id, title, order, wide?, select, render })`, `listCards()`; группы карточек `registerCardGroup({ id, order, wide?, items(state) → [{ id, title }], select(state, itemId), render(data, state, itemId) })` — по карточке на элемент (id `<группа>-<элемент>`); `expandCards(state)` — карточки и элементы групп по `order`; `requestRefresh()` — внеочередной опрос после действия (`setRefreshHandler` вызывает `app.js`) |
| `dom.js` | помощники `h`, `facts`, `pill`, `code`, `notice` (сообщение с подсказкой и списком), `plainInput` (поле с `autocapitalize=off`, `autocorrect=off`, `spellcheck=false`); текст только через `textContent` |
| `api.js` | `api(method, url, body?)`, `apiGet(url)`: JSON-запросы (изменяющие — с `Content-Type: application/json`), таймаут 15 с; ошибка — `ApiError` (`status`, `code`, `message`, `hint`, `blockers`) |
| `projects-card.js` | карточка «Проекты» (во всю ширину): корень новых проектов, список (имя, «создан»/«открыт», «папка не найдена», путь, «Убрать из списка» с подтверждением — папка остаётся), форма «Новый проект», кнопка «Открыть существующую папку…» |
| `folder-picker.js` | выбор папки: `GET /api/folders`, переход по подпапкам, «Вверх», «Домой», ввод пути, скрытые папки, «Открыть эту папку как проект»; ошибка доступа (macOS TCC) показывается с подсказкой |
| `structure-card.js` | карточка «Структура Kit» (во всю ширину): для каждого проекта из раздела `projects` — статус из раздела `structure` (`ok`, `нет`, `modified`, `outdated`, `newer`) с пояснением, предупреждения и заметки, раскрываемый список фрагментов (раскрытие переживает опрос), кнопки «Установить»/«Обновить» (`POST /api/projects/:id/structure`) и «Перезаписать изменённое…» (с подтверждением, `force: true`) |
| `system-card.js` | карточка «Система»: версия, ОС, компьютер, Node.js, каталог данных (с пометкой `WFK_DATA_DIR`), адреса панели, служба, время запуска |

## Как добавить карточку

Модуль JS вызывает `registerCard` и импортируется из `app.js`. Карточки,
число которых зависит от состояния (по одной на провайдера), регистрируются
группой (`registerCardGroup`). Модуль другого каталога подключается как
расширение: сервер монтирует его статику под своим префиксом, URL его
входного файла добавляется в `PANEL_EXTENSIONS`, а помощники панели он
получает в `install(shell)`.
`select(state)` выбирает данные карточки; карточка перерисовывается только
при изменении этих данных. Ошибка отрисовки показывается внутри карточки и
не ломает остальные. Карточка с собственным состоянием (формы, выбор
папки) возвращает из `render` один и тот же узел: он остаётся на месте, и
введённый текст и фокус переживают опрос. `wide: true` растягивает карточку
на всю ширину сетки.

## Инварианты

- JS проверяется `tsc` через JSDoc и `// @ts-check`.
- Данные вставляются в DOM только через `textContent`.
- Панель только читает `/api/state`; изменения — POST/DELETE с JSON.
- Поля ввода создаются через `plainInput` (без автозамены и заглавных
  букв на iPad), кнопки и строки списков — не ниже 44 px.
