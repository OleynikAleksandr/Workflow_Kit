## Замечания для следующей работы

- Создание сессии ChatGPT службой заняло около 4,5 минут (ожидание выгрузки треда демоном), хотя
  ревьюер ответил за 45 секунд; ревью не сломалось (ранний ход придержан), но первый круг
  задержался.
- Ревьюер не видит задачи плана через `scope:proposal`; основной агент сам перенёс состав задач в
  спецификацию. Стоит прямо просить состав задач в спецификации.
