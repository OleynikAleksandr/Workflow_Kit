  («Windows paths of a POSIX temp folder»), `darwin` и `linux` — на Windows, как раньше.

## Сборка и установка

Исходники: `908a5b8` (DOCS-R1) плюс повышение версии и CHANGELOG этой задачи; база — 0.14.1.
`package-lock.json` меняет только два поля версии.

```sh
npm run typecheck             # без ошибок
npm run check:platforms       # platform-guard: ok
npm test                      # test:app 1160 (1158 пройдено, 2 пропущено, 0 ошибок); test:kit 58 из 58
npm run build:kit             # Kit 2.2.5, бандл без изменений
node bin/wfk.mjs install      # app/0.14.2 вместо 0.14.1, удалена старая 0.14.0
~/.local/bin/wfk doctor --installed
curl -s http://127.0.0.1:4747/api/health
```

Тестов на один больше (новая проверка) и на один пропуск больше (вариант `win32` вне Windows),
чем в 0.14.1. После `npm test` в корне репозитория нет записей с `wfk-acw-` и с `\` в имени.

Doctor: все строки `ok`, «итог: всё в порядке», служба 0.14.2 (pid 46846), LaunchAgent
загружен, общий доступ ChatGPT «Работает». `/api/health`:
`{"ok":true,"version":"0.14.2","pid":46846,"startedAt":"2026-11-15T23:44:13.405Z"}`.
Работающие сессии пользователя не перезапускались: установка перезапустила только службу.
Живая проверка в панели не нужна: код службы и панели не менялся.
