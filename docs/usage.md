# Работа с Workflow Kit

Руководство для версии **0.11.0**. Что делать после [установки](setup.md): первый проект, диалог с агентом в панели и
особенности провайдеров. Краткое описание приложения — в [README](../README.md).

## Первая работа с проектом

1. Откройте панель и мастер проекта, выберите папку (в домашней папке или на другом диске) и
   провайдера первой сессии.
2. Просмотрите подготовительные действия и подтвердите их. Kit подготовит
   проект и откроет сессию. Для коммитов Git должна быть настроена ваша личность.
3. Опишите задачу в чате провайдера. Для разработки агент запрашивает решение:
   план с ревью, без ревью или «Просто обсуждаем».
4. При выборе ревью дождитесь обмена замечаниями. Затем выберите режим
   выполнения плана и запустите его в панели. Идёт спиннер со ступенями
   запуска, «Пауза» появится с первой задачей агента; если запуск не удался,
   карточка называет причину и предлагает «Начать заново».
5. Следите за задачами и строкой активности. Подтвердите выпуск, когда он нужен,
   проверьте результат и примите его. Закрытие плана — отдельное действие.
6. Если у ветки проекта есть удалённый репозиторий, после закрытия плана
   нажмите «Опубликовать на GitHub» на экране проекта (или попросите агента:
   `wfk project publish`). Пока план открыт, публикация не выполняется.

Сессия ревьюера скрыта из дерева проекта; её ответы доступны в журнале
основной сессии. При ошибке запуска ревью панель показывает причину и повтор.

## Версия Kit проекта

В шапке экрана проекта — версия Kit («Kit 2.2.4»). Если Kit в папке нет — «Kit не установлен»
и ссылка на мастер «Открыть папку проекта». Если Kit проекта старше версии приложения, на
экране есть карточка «Kit 2.2.3 → 2.2.4»:

- «Обновить Kit» — и есть согласие: Kit обновит свои файлы и хуки проекта одним коммитом,
  мастер и новая сессия не нужны, подтверждать ничего не надо. Хуки Kit в ChatGPT (Codex)
  служба одобряет сама, если папка доверена Codex; чужие хуки не одобряются.
- Пока Kit обновляется, карточка пишет «Kit обновляется…»; после — «Kit обновлён до …» и что
  сделано с хуками, при ошибке — текст Kit и его следующий шаг.
- Сессии, начатые до обновления, получат новый пакет Kit со следующей сессии.
- Kit новее версии приложения не заменяется старым.

## Раскладка панели

План, вопрос агента, ревью, выбор режима, подтверждение выпуска и активность выбранной
сессии находятся под деревом проектов слева. Диалог занимает правую область, его лента
прокручивается независимо от сайдбара; ввод остаётся в доступной части окна.

Перетащите границу областей, чтобы изменить ширину сайдбара. На границе также работают
стрелки влево/вправо и Home/End; двойной щелчок возвращает исходную ширину. Ширина
сохраняется на устройстве. На узком экране кнопка «Проекты и план» открывает ту же
панель; её закрывают кнопкой, Escape или нажатием на фон.

## Диалог с агентом

Щелчок по сессии открывает её чат в приложении и экран сессии в Kit с карточкой «Диалог»:
последние 100 реплик, новые появляются сами, и поле ввода до 20 000 знаков.
Enter отправляет сообщение, когда агент ждёт; Shift+Enter вставляет строку.
Во время работы обычный Enter вставляет строку, а Ctrl/⌘+Enter и кнопка «В очередь»
отправляют текст в прежнюю очередь. Поле растёт до ограниченной высоты, затем
прокручивается внутри. Новый черновик, набранный во время отправки, сохраняется.
Как сообщение доходит до агента:

- **Сразу, вашей репликой** — если агент ждёт: Claude в сессии, которую ведёт панель,
  ChatGPT при общем доступе к чатам. Панель пишет «Отправлено агенту».
- **Из очереди** — иначе: агент получит текст в конце хода или с вашим следующим
  сообщением в чате; Kimi получает очередь промптом. Панель пишет «В очереди».
- Сессии Claude, открытой вне панели, сообщения идут через очередь; запустить её в
  панели можно кнопкой «Продолжить» на экране сессии.

Под вводом Claude и ChatGPT показывают фактические модель, усилие, режим, кольцо
контекста и лимиты подписки. Нажатие на кольцо показывает токены и процент;
на лимиты — процент и местное время сброса. Нет данных — пустое кольцо или отсутствие
параметра; при ошибке сохраняются последние значения. Плюс и микрофон пока отключены.

У ChatGPT строка со стрелкой открывает меню модели, усилия, скорости, режима и
разрешений. Выбор действует со следующего хода, включая ход из приложения ChatGPT;
идущий ответ не меняется. Полный доступ требует «Продолжить» в меню. Зависимая
поправка усилия/скорости при смене модели объясняется под вводом. Недоступный каталог
или вариант показан с причиной. На macOS и Windows нужен работающий общий доступ
к чатам; на Linux приложения ChatGPT нет, изменение доступно через демон Kit.

Claude показывает данные без переключателей. Контекст и лимиты появляются у сессий,
запущенных или возобновлённых панелью после обновления; лимиты подписки — после первого
ответа, если Claude их передал. У старой или внешней сессии модель, усилие и режим
читаются из переписки, контекста может не быть. Kit вызывает прежнюю пользовательскую
команду строки состояния и сохраняет её вывод. Kimi и провайдеры без нового метода
показывают прежнюю модель и прочерки. Проверки и ограничения — [M25](evidence/M25-acceptance.md).

### Остановить ответ

Когда агент работает, основная кнопка ввода становится Stop. Пока остановка не
подтверждена, панель пишет «Останавливаю…». После подтверждения возвращается Enter;
история, черновик и очередь сохраняются. Stop удерживает автоматическое продолжение.
Новая явная реплика разрешает доставку сообщений; пауза плана снимается отдельно
штатной кнопкой «Продолжить». Задача не завершается и план не принимается автоматически.
Назначения исполнителей сохраняются, но нативные подагенты могут прерваться вместе с ходом.

Stop доступен только при подтверждённом состоянии и управлении сессией:

- Claude — живой pty Kit и распознанный рабочий экран, без диалога разрешений.
- ChatGPT/Codex — доступный Kit демон и конкретный ход; для Stop нужна версия Codex 0.167.2+.
- Kimi — сервер Kit, а не сервер приложения или чужой владелец; захвата сессии нет.

Если управление недоступно, причина показана рядом с отключённым Stop. Если ход уже
сменился, панель обновит состояние и предложит нажать Stop повторно — новый ход не
прерывается старым запросом. При тайм-ауте/ошибке видна подсказка, черновик остаётся.
На разрешения в родном приложении отвечайте там: Stop не принимает решения за вас.
После перезапуска службы состояние может быть неизвестным до следующего события хода;
обычная отправка сообщения остаётся доступной.

## Особенности провайдеров в работе

- **Claude.** Сессии Kit — сессии Remote Control Claude Code. Щелчок по сессии в панели
  открывает её в Claude Desktop, на iPad и телефоне — в приложении Claude.
- **ChatGPT.** Сессии Kit — чаты Codex в приложении ChatGPT. С общим доступом ([шаг 4, п. 5](setup.md#шаг-4-chatgpt-codex))
  чат сразу открыт везде, сообщения панели доходят сразу, чат ревьюера — с карточки «Ревью
  плана»; открывайте чаты из Kit (копия без значка глобуса — только для чтения). Без него чат
  открывается, когда Kit его отпустит, а чат ревьюера не виден.
- **Kimi Code.**
  - Пока приложение Kimi Code открыто, Kit работает через его сервер, иначе запускает свой
    `kimi web` на 127.0.0.1.
  - Ссылки на отдельную сессию у Kimi нет: щелчок открывает её проект в приложении, сессию
    выберите в списке проекта. Без приложения панель подскажет команду
    `kimi -S <id>` для терминала.
  - На iPad и телефоне — браузер через Remote Control Kimi (`code-rc.kimi.com`, платный тариф).
    Пока открыто приложение Kimi Code, Remote Control ведёт оно; без него — включите в панели
    Kit действием «Включить Remote Control Kimi».
  - План в сессии Kimi идёт последовательно или с исполнителями. Ревьюером Kimi не бывает: его
    план проверяет ChatGPT.
