# Работа с Workflow Kit

Руководство для версии **0.13.7**. Что делать после [установки](setup.md): первый проект, диалог с агентом в панели и
особенности провайдеров. Краткое описание приложения — в [README](../README.md).

## Первая работа с проектом

1. Откройте панель и мастер проекта, выберите папку (в домашней папке или на другом диске) и
   провайдера первой сессии.
2. Просмотрите подготовительные действия и подтвердите их. Kit подготовит
   проект и откроет сессию. Для коммитов Git должна быть настроена ваша личность.
3. Опишите задачу в чате провайдера. Для разработки агент запрашивает решение:
   план с ревью, без ревью или «Просто обсуждаем».
4. При выборе ревью дождитесь обмена замечаниями. Затем выберите режим
   выполнения плана и запустите его в панели. Идёт спиннер со ступенями
   запуска, «Пауза» появится с первой задачей агента; если запуск не удался,
   карточка называет причину и предлагает «Начать заново».
5. Следите за задачами и строкой активности. Подтвердите выпуск, когда он нужен,
   проверьте результат и примите его кнопкой «Принять план». Закрытие плана — отдельное
   действие: «Закрыть план». После каждой из этих кнопок агент отвечает одной-двумя фразами
   (M37).
6. Если у ветки проекта есть удалённый репозиторий, после закрытия плана
   нажмите «Опубликовать на GitHub» на экране проекта (или попросите агента:
   `wfk project publish`). Пока план открыт, публикация не выполняется.

Неначатый план принадлежит проекту, а не сессии (с 0.13.5, M31): карточка выбора способа и
карточка с «Начать выполнение плана» видны в любой сессии проекта — например, в новой сессии
другого провайдера или модели. Сессия, в которой вы нажали кнопку, становится владельцем плана,
прежняя перестаёт ждать. Начатый план остаётся у своей сессии; другие показывают «План выполняет
сессия «…»» и «Открыть сессию». Для старта из другой сессии нужен Kit проекта 2.2.5.

План закрывается только при чистой папке проекта (M37). Если после выполнения плана в ней
остались файлы вне коммитов (например, временный JSON агента), карточка плана называет их и
предупреждает: «Пока они есть, план не закроется». Кнопка «Попросить агента убрать» отправляет
просьбу сессии-владельцу плана: агент удаляет свои временные файлы, коммитит документы, а код
и файлы, которые создал не он, не трогает и называет вам. Если владельца нет или его сессия не
получает сообщений Workflow Kit, кнопка отвечает, что файлы нужно убрать самому. «Закрыть
план» при оставшихся файлах отказывает и называет их. С Kit проекта 2.2.6 агент кладёт входные
JSON команд в `.harness/inputs/` — папка не попадает в git и закрытию не мешает.

Решения записывает Kit (M40, проект на Kit 2.4.x): выбор режима, подтверждение выпуска,
приёмку, закрытие и другие решения принимают кнопки панели или ваше сообщение в чате. После
«Подтвердить выпуск» задачу начинает сама служба, агент получает «задача начата». Если агент
вызвал решение сам (например, `accept --note`), Kit ничего не меняет, а в панели появляется
карточка этого решения. Новые карточки: «Снять блокировку» (с причиной), установка
инструментов (с точными командами — нажатие ставит ровно их, даже если агент потом поменял
файл) и «Принять коммиты» сделанные в обход Kit (со списком SHA). Если вы ответили в чате
(«принимаю», «выбираю последовательно»), агент вызывает `wfk decision <вид>`, и служба берёт
ваши слова из вашего сообщения этого хода; сообщение из прошлого хода или ещё не доставленное
агенту не подходит — тогда нажмите кнопку.

Сессия ревьюера скрыта из дерева проекта; её ответы доступны в журнале
основной сессии. При ошибке запуска ревью панель показывает причину и повтор. Карточка
«Ревью плана» видна, пока её план предложен или выполняется; после закрытия плана и после
предложения другого плана она исчезает (M37).

## Версия Kit проекта

В шапке экрана проекта — версия Kit («Kit 2.2.7»). Если Kit в папке нет — «Kit не установлен»
и ссылка на мастер «Открыть папку проекта». Если Kit проекта старше версии приложения или
устарела структура Kit (файлы `wfk`: раздел `AGENTS.md`, хуки Claude и ChatGPT, шаблоны,
`.workflow-kit/manifest.json`), на экране есть карточка: «Kit 2.2.6 → 2.2.7», «Структура Kit
3 → 4» или обе стрелки сразу («Kit 2.2.6 → 2.2.7, структура 3 → 4»):

- «Обновить Kit» — и есть согласие: Kit обновит свои файлы, структуру и хуки проекта одним
  коммитом, мастер и новая сессия не нужны, подтверждать ничего не надо. Хуки Kit в ChatGPT
  (Codex) служба одобряет сама, если папка доверена Codex; чужие хуки не одобряются.
- Файлы структуры, изменённые вручную, кнопка не перезаписывает: карточка заранее пишет
  «Изменено вручную, не обновится: …». Если файл структуры изменён и не закоммичен, структура
  не обновляется вовсе (Kit обновляется), карточка называет такие файлы — закоммитьте или
  уберите их и нажмите кнопку снова.
- Пока Kit обновляется, карточка пишет «Kit обновляется…»; после — «Kit обновлён до …» или
  «Структура Kit обновлена до …», коммит, файлы структуры и что сделано с хуками, при ошибке —
  текст Kit и его следующий шаг. Если Kit отказал, записанные файлы структуры возвращаются.
- Сессии, начатые до обновления, получат новые хуки и пакет Kit со следующей сессии: Claude и
  ChatGPT читают хуки при старте сессии.
- Структура 4 добавила хуки вопроса Claude (`AskUserQuestion`). В сессии без них ожидающий
  вопрос агента в диалоге панели не появляется: панель видит его только после ответа в
  приложении Claude. Обновите Kit и начните новую сессию.
- Kit новее версии приложения не заменяется старым.
- Обновление до Kit 2.4.x (и новый проект) включает решения через Kit (`decisions: host`,
  M40): ваши решения записываются только кнопками панели или вашим сообщением в чате, ручные
  формы агента (`accept --note`, `--confirmed`) превращаются в карточки решений. Проект на Kit
  2.3.x работает по-прежнему, пока вы его не обновите.

## Раскладка панели

План, вопрос агента, ревью, выбор режима, подтверждение выпуска и активность выбранной
сессии находятся под деревом проектов слева. Диалог занимает правую область, его лента
прокручивается независимо от сайдбара; ввод остаётся в доступной части окна.

Перетащите границу областей, чтобы изменить ширину сайдбара. На границе также работают
стрелки влево/вправо и Home/End; двойной щелчок возвращает исходную ширину. Ширина
сохраняется на устройстве. На узком экране кнопка «Проекты и план» открывает ту же
панель; её закрывают кнопкой, Escape или нажатием на фон.

## Диалог с агентом

Щелчок по сессии открывает её чат в приложении и экран сессии в Kit с карточкой «Диалог»:
последние 100 реплик, новые появляются сами, и поле ввода до 20 000 знаков.
Enter отправляет сообщение, когда агент ждёт; Shift+Enter вставляет строку.
Во время работы обычный Enter вставляет строку, а Ctrl/⌘+Enter и кнопка «В очередь»
отправляют текст в прежнюю очередь. Поле растёт до ограниченной высоты, затем
прокручивается внутри. Новый черновик, набранный во время отправки, сохраняется.
Как сообщение доходит до агента:

- **Сразу, вашей репликой** — если агент ждёт: Claude в сессии, которую ведёт панель,
  ChatGPT при общем доступе к чатам. Сообщение появляется в ленте.
- **Из очереди** — если агент отвечает: сообщение стоит в конце ленты пузырём с пометкой
  «в очереди» и уходит агенту в конце хода или сразу после Stop; Kimi получает очередь
  промптом. Пузырь пропадает, когда сообщение выдано агенту.
- Исправления Stop и доставки Claude (0.13.1) действуют в сессиях, запущенных или
  возобновлённых панелью после установки 0.13.1.
- Сессии Claude, открытой вне панели, сообщения идут через очередь; запустить её в
  панели можно кнопкой «Продолжить» на экране сессии.

Длинный диалог ChatGPT (с 0.13.6, M32) загружается порциями: над лентой видно «Загружаем
диалог…», пока не придут последние реплики. Элемент, который слишком велик для передачи,
заменяет пометка «Часть диалога Codex недоступна…»; реплики до и после него видны, полный
текст — в чате ChatGPT. Если пропала связь с демоном Codex, под лентой появляется
«Восстанавливаем подключение к Codex…», через 30 секунд — совет проверить демон в настройках
провайдера. Лента, черновик, прокрутка и очередь остаются; когда демон вернётся, лента
обновится сама, перезагружать панель не нужно, повторно ничего не отправляется.

Под вводом нет служебных строк: виден только ряд параметров, а ошибка появляется лишь после
вашего действия и говорит, что сделать. Claude и ChatGPT показывают фактические модель,
усилие, режим, кольцо контекста и лимиты подписки. Нажатие на кольцо показывает токены и
процент; у Claude контекст считается от порога автосжатия `autoCompactWindow`, если он
задан (как `/context` Claude), а окно модели показано второй строкой;
на лимиты — процент и местное время сброса. Нет данных — пустое кольцо или отсутствие
параметра; при ошибке сохраняются последние значения. Плюс и микрофон пока отключены.

У ChatGPT правая строка открывает компактную карточку усилия: уровень выбирается
ползунком, молния переключает скорость и показывает подсказку о расходе. Нажатие
на название модели открывает отдельный список под вводом; в нём остаётся выбор
обычного/планового режима. Доступ — отдельная плашка слева у плюса: «Запрашивать
разрешение», «Подтверждать за меня» и «Полный доступ» с описаниями. Эти пресеты
используют штатную проверку Codex. Полный доступ оранжевый и требует «Продолжить»;
«Отмена» ничего не записывает. Круговой стрелки и ссылки «Подробнее» нет.

Выбор действует со следующего хода, включая ход из приложения ChatGPT; идущий ответ
не меняется. Поправки несовместимых усилия/скорости при смене модели видны в контролах.
Успешная смена параметров не пишет служебный подстрочник; ошибки остаются видимыми. Недоступные варианты показаны с причиной, неизвестное значение не
подменяется. Клавиатура: стрелки/Home/End, Esc для отмены и закрытия; бегунок можно схватить и тянуть в обе стороны, один запрос
по отпусканию, включая отпускание за пределами дорожки. На macOS и Windows нужен общий доступ к чатам; на Linux —
демон Kit. Проверки и ограничения — [M26](evidence/M26-native-controls.md).

### Параметры Claude

У Claude название модели и Effort открывают компактное меню как в Claude Desktop.
Основные модели находятся сразу в нём, дополнительные — в **More models**.
**Effort** открывает Low/Medium/High/Extra/Max для выбранной модели; Recommended
показывает рекомендацию Claude. Здесь список, а не ползунок ChatGPT.
**Ultracode** — отдельный переключатель; он сохраняет базовое усилие.

Отдельная кнопка режима предлагает **Auto**, **Manual**, **Accept edits** и **Plan**
с описаниями. Plan — один из этих режимов. Ограничения native Remote Control и
аккаунта сохраняются; недоступная скорость не предлагается для включения. В проверенном
аккаунте fast требует usage credits. Успех проходит без подстрочника, ошибка видна.

Изменения относятся только к выбранной беседе, не меняют пользовательские defaults
и не запускают ответ. Меню открыты всегда, и во время ответа Claude (с 0.13.3, M29): выбор
сразу виден в строке с пометкой «применяется», «применится, когда Claude закончит ответ»
или «применится, когда поле ввода Claude опустеет», а Kit применяет его в терминале сам,
когда ввод Claude свободен. Черновик в панели Kit сохраняется. Если Claude не принял
выбор, под вводом на 10 с появляется строка с причиной, и строка параметра возвращается
к прежнему значению. В режиме Plan Claude показывает свою модель плана.
С 0.13.4 (M30) эти изменения не оставляют служебных строк в ленте беседы в Claude Desktop;
видна только `/effort ultracode` при явном переключении Ultracode.
Вложенное меню открывается мышью, кликом или ArrowRight; Home/End и стрелки выбирают
пункт, ArrowLeft возвращает назад, Esc закрывает. На узком экране есть Back.

Нужны Claude Code **2.1.323+** и новый управляемый host: запуск или штатное возобновление
панелью после установки 0.13.3. Старые/внешние беседы остаются для чтения с причиной,
без скрытого перезапуска. Контекст/лимиты появляются при новых запусках; лимиты
подписки — после ответа, если Claude их передал. Пользовательская строка состояния
сохраняется. Старое значение ultra отображается как Ultracode без выдуманного базового
effort. Проверки и ограничения — [M27](evidence/M27-claude-native-controls.md).
Kimi и провайдеры без нового метода сохраняют прежнюю модель и прочерки.

### Остановить ответ

Когда агент работает, основная кнопка ввода становится Stop; у Claude она активна весь ход.
Пока остановка не подтверждена, кнопка показывает занятость. После подтверждения возвращается Enter;
история, черновик и очередь сохраняются. Stop удерживает автоматическое продолжение.
Новая явная реплика разрешает доставку сообщений; пауза плана снимается отдельно
штатной кнопкой «Продолжить». Задача не завершается и план не принимается автоматически.
Назначения исполнителей сохраняются, но нативные подагенты могут прерваться вместе с ходом.

Stop доступен только при подтверждённом состоянии и управлении сессией:

- Claude — сессия, которую ведёт терминал Kit. Stop отправляет одно Esc и в диалоге
  разрешения: это отказ, команда не выполняется. Сессию, открытую только в приложении
  Claude, остановите там («Остановите ответ в приложении Claude»).
- ChatGPT/Codex — доступный Kit демон и конкретный ход; для Stop нужна версия Codex 0.167.2+.
- Kimi — сервер Kit, а не сервер приложения или чужой владелец; захвата сессии нет.

Если управление недоступно, причина появляется под вводом после нажатия Stop. Если ход уже
сменился, панель обновит состояние и предложит нажать Stop повторно — новый ход не
прерывается старым запросом. При тайм-ауте/ошибке видна подсказка, черновик остаётся.
На разрешения в родном приложении отвечайте там: Stop не принимает решения за вас.
После перезапуска службы состояние может быть неизвестным до следующего события хода;
обычная отправка сообщения остаётся доступной.

## Особенности провайдеров в работе

- **Claude.** Сессии Kit — сессии Remote Control Claude Code. Щелчок по сессии в панели
  открывает её в Claude Desktop, на iPad и телефоне — в приложении Claude.
- **ChatGPT.** Сессии Kit — чаты Codex в приложении ChatGPT. С общим доступом ([шаг 4, п. 5](setup.md#шаг-4-chatgpt-codex))
  чат сразу открыт везде, сообщения панели доходят сразу, чат ревьюера — с карточки «Ревью
  плана»; открывайте чаты из Kit (копия без значка глобуса — только для чтения). Без него чат
  открывается, когда Kit его отпустит, а чат ревьюера не виден.
- **Kimi Code.**
  - Пока приложение Kimi Code открыто, Kit работает через его сервер, иначе запускает свой
    `kimi web` на 127.0.0.1.
  - Ссылки на отдельную сессию у Kimi нет: щелчок открывает её проект в приложении, сессию
    выберите в списке проекта. Без приложения панель подскажет команду
    `kimi -S <id>` для терминала.
  - На iPad и телефоне — браузер через Remote Control Kimi (`code-rc.kimi.com`, платный тариф).
    Пока открыто приложение Kimi Code, Remote Control ведёт оно; без него — включите в панели
    Kit действием «Включить Remote Control Kimi».
  - План в сессии Kimi идёт последовательно или с исполнителями. Ревьюером Kimi не бывает: его
    план проверяет ChatGPT.
