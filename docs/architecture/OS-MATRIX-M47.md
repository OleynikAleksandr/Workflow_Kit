# Матрица ОС: M47 (подтверждение вставки по хуку, метка сборки хоста)

Часть [матрицы ОС](OS-MATRIX.md): строки вехи M47 ведутся здесь, чтобы основной документ
оставался в пределах размера. Правила те же: каждое изменение дополняет таблицу в том же коммите.

| Возможность | macOS | Linux | Windows |
| --- | --- | --- | --- |
| M47 T001: прямую отправку подтверждает первый хук `UserPromptSubmit` сессии в окне отправки (текст в обёртке `<pasted_content>` Claude 2.1.328) | общий код службы (`agent-channel`) | то же | то же; ветки ОС нет |
| M47 T002: строка пользователя в ленте без пары меток `<pasted_content id>` | общий `chat.ts` | то же | то же; ветки ОС нет |
| M47 T003: метка сборки хоста (`hostBuild`) и причина `HOST_OUTDATED` у сессии старой сборки | хост `session.exp` + `interrupt-worker.ts` | то же | хост `pty/host.ts` (ConPTY), x64/ARM64; пути через `path`, содержимое с LF — метка не зависит от CRLF; тест хоста ConPTY пишет метку; ветки ОС нет |
