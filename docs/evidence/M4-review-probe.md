# Проба перекрёстного ревью (M4, задача T001)

Дата: 2026-11-08, служба 0.3.16, временный проект `~/WorkflowKitProjects/probe-review`
(создан мастером панели через API, провайдер ChatGPT; доверие Claude тоже выдано мастером).

## ChatGPT: сессия, созданная службой, получает сообщение через `Stop`

- Первая сессия мастера (служба, первое сообщение через демон `codex remote-control`): ход
  закончился, хук `Stop` пришёл в службу (`channel`: `waiting`, `lastAssistantMessage` — ответ
  агента «AGENTS.md прочитан…»).
- Новая сессия `POST /api/projects/1b7190ca0f95/providers/codex/sessions`; как только канал увидел
  её (`working`, 09:18:38), в очередь ушло «ответь одним словом PONG-CODEX». В 09:18:42 сессия
  `waiting`, последнее сообщение `PONG-CODEX`: ответ `block` хука `Stop` продолжил ход в демоне.
- Таймаут хука `Stop` у Codex в проекте — `timeoutSec: 600`, у Claude — `timeout: 600`: удержание
  на `STOP_HOLD_MS` (9 минут) укладывается.

## Claude

- Сессия Claude, созданная без первого сообщения, хуков не присылает (хода нет), канал её не знает:
  сообщение панели ушло в очередь (200), но разбудить нечего. Поэтому ревьюер Claude создаётся
  только с первым сообщением (`createSession(…, { firstMessage })`, как первая сессия мастера) —
  этот путь работает с вехи 2 (мастер «Первая сессия» Claude).
- Удержание `Stop` и ответ `block` для Claude проверены автопилотом и выбором режима (вехи 2–3);
  пробуждение ожидающей Claude — M3-fixes R9.
