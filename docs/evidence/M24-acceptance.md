### Что проверено

- Карточки плана и решений находятся под деревом в слоте sessionSidebar; справа нет
  копии plan-card. sessionBody сохранён как совместимый слот расширений.
- Resize мышью: ширина 426 px записалась в localStorage. Клавиши End/Home/ArrowRight
  дали 560/240/256 px; двойной щелчок вернул 320 px. Pointer cancel снял drag-состояние.
  Неверное значение хранилища не сломало страницу: восстановились 320 px.
- Синтетический touch через Chromium CDP Input.dispatchTouchEvent дал ширину 436 px.
  Это тест Pointer Events в браузере, не живая проверка пальцем на iPad.
- Drawer открывается, удерживает фокус, закрывается Escape и по фону, возвращает фокус.
  В скрытой панели сохраняется индикатор требуемого действия.
- После опроса сохранены черновик, фокус и прокрутка ленты. После переключения сессий
  черновик первой сессии вернулся, положение ленты — 100 → 100 px, чужого плана нет.
  При проверке обнаружен сброс scrollTop снятого DOM; исправлен в slotPart до коммита.
- Прогресс плана не сбрасывает текст и фокус формы исправлений. Форма подтверждения
  выпуска переживает опрос. Раскрытия журнала [true,false,true] сохранились при смене
  активности. Проверены ready, start-pending, running, paused, blocked, acceptance,
  accepted; вопрос с тремя вариантами, выбор с двумя вариантами, выпуск, ревью, пустой план.
- Центры ответвлений совпадают с центрами карточек с учётом границы и толщины линии.
  Высоты тестовых карточек: 78.09, 59.24, 115.77 px. Последний радиус — 10 px,
  свободного хвоста нет. Одна сессия получает конечное скругление; пустое дерево и
  свёрнутый проект не содержат ветвей.
- Длинный предпросмотр мастера (1349 px) и ход подготовки (1562 px) прокручиваются
  внутри main высотой 667 px; кнопки внизу достигаются scrollIntoView. Настройки
  (1249 px) и архив (825 px) также прокручиваются; при смене экрана main начинает с 0.

### Матрица viewport

В обеих темах проверены 1920×1080, 1280×800, 1024×768, 768×400, 375×667 CSS px.
Страница сессии не переполняет viewport; лента имеет собственную прокрутку.
На 768×400 обычная кнопка отправки заканчивается на y=360 px; при длинной ошибке —
на y=371.63 px, внутри окна. Проверены пустая/неподдерживаемая лента, длинная ошибка
и многострочный ввод. Будущий компактный ввод и Enter/Stop проверяются в T006.

Эквивалент 200% масштаба проверен CDP Emulation.setDeviceMetricsOverride:
640×400 CSS px, DPR=2 (эквивалент окна 1280×800 при 200%). Ввод заканчивается на
323 px, кнопка на 369 px; размер документа 640×400. Это эмуляция метрик, не проверка
ручного масштабирования пользовательского браузера.

Замеры: [T001-browser-results.json](M24/T001-browser-results.json).

### Изоляция и команды

Браузер — существующий Playwright MCP (`browser_run_code_unsafe`, page.route,
page.evaluate, page.screenshot; снимки просмотрены через view_image).
Временный сервер: `python3 -u /tmp/wfk-m24-server.py`, адрес `http://127.0.0.1:48761`.
Он отдаёт только исходную статику четырёх модулей с текущим CSP. Все `/api/**`
перехвачены page.route, состояние — fixtures из `/tmp/wfk-m24-fixture.json` по типам
и тестам моделей. POST/DELETE имитируются в памяти; настоящая служба на 4747,
проекты, процессы провайдеров и пользовательские сессии не использовались.

Запуск целевых тестов:

```sh
node --test product-parts/control-panel/clusters/web-panel/modules/panel-shell/test/layout-model.test.ts product-parts/control-panel/clusters/web-panel/modules/panel-shell/test/panel-shell.test.ts product-parts/control-panel/clusters/web-panel/modules/session-view/test/session-model.test.ts
npm run typecheck
```

Целевые тесты: 28/28. Проверки полного коммита выполняет Kit: typecheck, test,
platform-guard, doc-size, md-links, file-lines, docs-contracts, conflict-markers.
Их успешное завершение подтверждается результатом команды commit, не одним этим документом.
