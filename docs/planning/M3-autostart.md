# M3: всё нужное поднимается при старте службы

Скоуп `m3-autostart` (после закрытого `m3-fixes`).

## 1. Замечание

2026-11-07, после перезагрузки Mac: на главном экране индикатор ChatGPT оранжевый —
«демон не запущен». Демон Codex (`codex remote-control start`) Workflow Kit запускал только по
кнопке «Запустить демон», а после перезагрузки его никто не запускает.

## 2. Решение пользователя (2026-11-07)

Служба Workflow Kit — LaunchAgent, macOS запускает её при входе в систему; без службы панель
не работает ни на Mac, ни на iPad и телефоне. Поэтому всё, что нужно Workflow Kit, служба
поднимает при своём старте, без кнопок и подтверждений:

- **Демон Codex.** Codex установлен (не Windows), демон не работает или работает, но не
  подключён к ChatGPT (`disabled` / `errored`) — служба выполняет `codex remote-control start`.
  Подключается (`connecting`) или подключён — не трогает. Неудача пишется в журнал и
  повторяется: всего 3 попытки с паузой 30 с (сразу после входа в систему сеть и вход Codex
  могут быть ещё не готовы). Индикатор показывает обычное состояние демона.
- **Окружения Remote Control папок Claude.** Окружение, запущенное кнопкой проекта и не
  остановленное намеренно (`processId` есть, `stoppedAt` нет), процесс не жив — поднимается
  так же, как прерванные сессии (раунд R9); проекты из архива не трогаются.
- При остановке службы (в том числе при обновлении) демон Codex и процессы Claude не
  останавливаются.

## 3. Контракт

- `Provider.autostart?()` — поднять то, что провайдеру нужно на весь Mac, при старте службы;
  ответ — строка для журнала или `null`, если ничего делать не нужно. Codex — демон.
- Реестр: `autostart()` → `{ started: string[], errors }` по провайдерам.
- Claude `resumeInterrupted(project)` поднимает и прерванное окружение проекта; в ответе —
  `environment` среди id.
