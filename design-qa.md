Скриншоты пользователя — кропы, не размеры полного окна. Оригиналы не изменены.

состояния, что на PNG; настоящий адаптер получает множитель из каталога модели.

Full-view: docs/evidence/M26/panel-dark.png (2560×1600), source access screenshot

микрофона справа, отсутствие повторения доступа в модели и отсутствие общего списка.
Focused: effort-dark.png (510×194 → 255×97 CSS), access-dark.png

## Findings и история исправлений

1. [P1, исправлено] Базовый CSS перекрывал карточку: 340px, радиус 12px и цвет темы
   Kit вместо 255×97/18px/нативного серого. Исправлена специфичность native popup.
2. [P1, исправлено] Новые значки отображались квадратами: поздний shorthand mask
   обнулял mask-image. Поднята специфичность локальных масок Lucide.
   До исправления: effort-before-qa.png и access-before-qa.png в docs/evidence/M26.
3. [P2, исправлено] Меню доступа 170px высотой, слишком светлая поверхность,
   неверные отступы и размер иконок. Теперь 644×162, #242424, иконки 14px,
   строки 43px. effort #303030, заполнение/бегунок белые, трек/точки серые.
4. [P1, исправлено] На 375px строка модели сжималась до вертикальных обрывков букв.
   Группа получила минимальную читаемую ширину и переносится целиком.
   Финальные panel-dark-375.png, panel-light-375.png и touch-*.png проверены визуально.
5. [P2, исправлено] Широкое меню выравнивалось правым краем у левой плашки и
   попадало поверх дерева проектов. Теперь начало привязано к левому краю плашки
   с ограничением viewport; panel-dark.png подтверждает положение над composer.
6. [P2, исправлено] Подсказка переносила вторую строку. Размер шрифта 12,5px и
   отступы 6/12px сохраняют две строки при ширине 170px; effort-context.png.
7. [P2, исправлено] Polling мог вернуть подпись усилия к серверной во время жеста;
   неизвестное значение могло показывать первую подпись. Preview сохраняется,
   неизвестное усилие показывает «Нет данных» и скрытый неактивный ползунок.
8. [P2, исправлено] Busy показывал ложную причину «Скорость недоступна»; теперь
   временная блокировка не подменяет причину провайдера. Размер поповера повторно
   рассчитывается после обновления и при переключении подтверждения.

После каждой серии изменений реализация переснята и сравнена повторно; финальные
совместные сравнения effort-context.png и panel-dark.png не выявили P0/P1/P2.

## Обязательные поверхности

- Шрифт: системный стек -apple-system / SF Pro Text / system-ui; основной 14px/400,
  модель 12px, описания 12px/16px. Фирменные шрифты не распространяются. Переносы
  на desktop соответствуют эталону; на touch адаптивны. Незначительная разница
  антиалиасинга браузера и нативного приложения допустима (P3).
- Геометрия: размеры 255×97 и 644×162, радиусы 18, ритм заголовка/модели/трека
  и меню проверены. Различие полупрозрачности поверх иного фона допустимо (P3).
- Цвет: нейтральные поверхности, белый ползунок, приглушённая модель; full orange.
  В светлой теме оранжевый темнее для читаемости; отдельного светлого эталона нет.
- Изображения/значки: raster декораций нет; локальные исходные Lucide 0.468.0,
  без emoji/custom SVG. Молния использует заполнение currentColor исходного контура.
  Щит auto из согласованной библиотеки, без распространения фирменного artwork.
- Текст: три подписи и описания соответствуют PNG. Сброс и Подробнее исключены
  пользователем, отдельный список моделей под вводом — его уточнение, не дефекты QA.

## Браузерные действия

Проверены drag и точка/клавиатура Home/End, один POST по завершении, pointercancel
и Esc без записи; модель отдельным поповером, закрытие после выбора; режим,
скорость и подсказка; три пресета, full до подтверждения 0 POST, отмена 0 POST,
Продолжить один confirmed:true. Причины политик, одиночный/частичный каталог,
неизвестное усилие, GET/POST 503, блокировка обоих якорей, сохранение draft/focus,
polling во время жеста и задержанный GET после POST проверены. Enter отправляет
сообщение и очищает только свой draft; legacy Claude сохраняет прежнюю строку/плюс.
Контроль pageerror, console error, HTTP ресурсов и CSP на финальном рендере: 0 ошибок.
Ожидаемые 503 проверялись отдельно, они не объявлены успешными запросами.

Dark/light: 1920×1080, 1280×800, 1024×768, 768×400, 375×667 — оба поповера внутри
viewport, нет горизонтального overflow. Скриншоты panel-{dark,light}-{375,768}.png.
200%: 640×400 CSS/DPR2 как эквивалент доступной CSS-площади 1280×800 при 200%,
zoom-200-equivalent.png; это не проверка системного zoom Safari.
Touch: Chromium hasTouch/isMobile, 375×667/DPR2, реальный browser touch drag через CDP,
один POST; range 229×44, speed 44×44, model высота 44, строки доступа 66–82px.
Уменьшение viewport до 375×350 эмулирует доступное место с клавиатурой: меню
359×247 по y95, нижний край342≤350−8. Настоящий iPad не проверен.
