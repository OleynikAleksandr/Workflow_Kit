# M28: факты для исправлений контролов Claude

Исследование к [спецификации M28](../planning/M28-claude-controls-fixes.md). Проверенное
помечено **[проверено]**, остальное **[не проверено]**. Стенд T001 и сырые наблюдения —
[evidence M28](../evidence/M28-claude-controls-fixes.md).

## 1. Окно контекста и порог автосжатия

- **[проверено]** Claude Code 2.1.325 собирает `context_window` для statusline из окна
  модели: `context_window_size` — окно модели (`opus[1m]` → 1 000 000),
  `used_percentage = round((input + cache_creation + cache_read) / окно × 100)`,
  `total_input_tokens` — токены текущего контекста.
- **[проверено]** `autoCompactWindow` в данные statusline не входит; его учитывают
  `/context` и панель Context приложения Claude.
- **[проверено]** Порядок через `claude -p "/context"` (без генерации) в своей папке:

| Набор | Итог `/context` |
| --- | --- |
| Только пользовательский `modelSettings.claude-opus-5-5` 500 000 | 500k |
| + проектный `modelSettings` 300 000 | 300k |
| + локальный `modelSettings` 250 000 | 250k |
| Локальный общий 220 000 против проектного модельного 300 000 | 220k |
| Переменная `CLAUDE_CODE_AUTO_COMPACT_WINDOW=200000` поверх слоёв | 200k |
| `--settings '{"autoCompactWindow":180000}'` поверх слоёв | 180k |
| Переменная 200 000 и `--settings` 180 000 | 200k |
| Локальный модельный `"auto"` (пользовательский 500 000 есть) | 1m |
| Локальный ключ-алиас `opus` 260 000 | 260k |
| Локальный общий 5 000 или 5 000 000 | 300k (пропущен) |

- **[проверено по коду]** Диапазон порога 100 000–1 000 000. Managed-источники: файл
  `managed-settings.json` в `/Library/Application Support/ClaudeCode` (macOS),
  `/etc/claude-code` (Linux), `C:\Program Files\ClaudeCode` (Windows), а также MDM
  (plist или реестр) и серверные настройки организации.
- **[не проверено]** Место managed-файла относительно переменной окружения: без прав
  администратора не проверялось.

## 2. Кадры экрана 2.1.325

Фикстуры: `provider-claude/test/fixtures/m28/claude-2.1.325-frames.json`.

- **[проверено]** Работа: строка над полем ввода `· Schlepping… (16s · ↓ 206 tokens)`;
  значок меняется (`·✢✳✶✻✽`), в скобках — время, токены, `thinking with low effort`,
  `running UserPromptSubmit hook`, `running Stop hook`. Текста `esc to interrupt` нет.
- **[проверено]** Итог хода: `✻ Churned for 23s · done 9:04 AM` (без многоточия).
- **[проверено]** Свободен: строка `❯` между двумя линиями; после хода Claude ставит в
  поле ввода подсказку («проверь ещё раз») — это не черновик.
- **[проверено]** Диалог разрешения: «Do you want to proceed?», варианты 1–4,
  «Esc to cancel · Tab to amend»; Kit распознаёт его как `dialog`.
- **[проверено]** Хост Kit во время работы держал `interrupt-state` = `idle`, `epoch` —
  `:0`; движок параметров — `idle`.

## 3. Хуки, канал и транзакции параметров

- **[проверено]** Обычный ход: prompt-хук в начале, Stop-хук в конце, ответы
  `{"answer":null}`.
- **[проверено]** После Esc Stop-хука нет. Канал оставался `working` с начала прерванного
  хода, `pending: 2`; для Stop — «Нет свежего состояния управляемого терминала Claude;
  обновите сессию».
- **[проверено]** Сообщение маршрутом панели свободному, но «working» по каналу агенту
  получило `{"queued": …}`; нового хода не началось.
- **[проверено]** Смена усилия low → medium движком прошла за 4 с, пока агент был свободен.
- **[проверено по коду]** Во время транзакции `nativeControlHook` возвращает `true` для
  любого хука: Stop не доходит до канала, prompt получает `decision: block`.
- **[проверено в M27]** Встроенные команды (`/model`, `/effort`, Shift+Tab) хуков не
  порождают.

## 4. Esc в диалоге разрешения

- **[проверено]** Одно Esc в диалоге разрешения: команда не выполнена (файл не создан),
  ход остановлен; экран «Interrupted · What should Claude do instead?», итог
  `✻ Baked for 1s · done`; в транскрипте `[Request interrupted by user for tool use]`.
- **[проверено]** Метки `[Request interrupted by user]` в потоке терминала нет.
- **[не проверено]** Esc во время генерации и Stop из приложения Claude — T007.

## 5. Бюджет живых ходов

Не больше 6 коротких ходов на самой дешёвой модели каталога, в своём временном проекте
Kit с очисткой: T001 — 2 из 3 (Haiku 5.5, low), T007 — до 3 (T008 — только остаток T007).
