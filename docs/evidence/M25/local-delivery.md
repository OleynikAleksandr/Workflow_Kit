# M25 / T008: локальная поставка 0.11.0

Разрешение пользователя: «заранее даю тебе добро на все действия, на выбор тобой
самостоятельно», выполнить весь план без участия и без выборов в диалоге. Оно передано
в task:start --confirmed. Пользовательскую приёмку и закрытие scope агент не выполняет.

его точный хеш после появления коммита записывает T009 (самохеш в своём коммите невозможен).
