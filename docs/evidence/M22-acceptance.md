## Не проверено и известные дефекты (**П**)

- Одобрение хука Codex после «Обновить Kit» вживую агентом не проверено: во временной службе
  провайдеры были заглушками; путь покрыт тестами `kit-update` (в том числе команда win32).
- Kit новее версии приложения не понижается: карточки нет, только строка версии.
- Kimi Code: одобрение хука пишет файл и делается только мастером, как в M21.
- Этот репозиторий обновляется до Kit 2.2.4 карточкой после закрытия scope.
- Harness AI не менялся: синхронизация модулей Kit — по отдельной просьбе пользователя.
- `package-lock.json` остался с версией корня 0.9.2: проверка Kit `kit:file-lines` считает и
  lock-файл (538 строк после esbuild с его платформенными пакетами, лимит 400), а lock-файл не
  делится. Зависимости в нём верны, `npm ci` версию корня не сверяет. Исправление — в Kit
  (`kit:file-lines` пропускает lock-файлы), отдельной работой.
