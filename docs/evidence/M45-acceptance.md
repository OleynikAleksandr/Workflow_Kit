# M45: доказательства — доставка сообщений в терминал Claude

Спецификация — [M45-claude-terminal-delivery.md](../planning/M45-claude-terminal-delivery.md).
План выполняется под живым запуском автопилота `run-FaBBeFOCW1rL` с разрешением Kit 2.4.6 (первый
план после M44: запуск получил разрешение и с ручным критерием 5).

## Причина (19.11.2026, сессия `ffc970ed`, лог Claude и файлы параметров)

- Хост параметров панели набирал `/model`, чтобы прочитать каталог моделей: кэш каталога —
  для CLI 2.1.325, сессия — на 2.1.328, поэтому три попытки на каждый запуск хоста. Меню жило до
  55 с.
- Сообщения десктопа (Remote Control, `Injecting inbound user message`) ждали закрытия меню:
  «Да, конечно, разрешаю» — 09:23:52 → 09:24:31.
- Сообщение панели отменяло транзакцию, но через 2 с вставлялось в любой терминал: в 09:03:56
  ход так и не начался (ни хука, ни запроса), сообщения десктопа ждали до «Стоп» в 09:11:43;
  в 09:24:31, 09:31:27 и 09:56:40 перед сообщением десктопа терминал выполнил `/model`, а
  поручения из панели пропали. Панель считала их доставленными (`MESSAGE_SENT`).
- Режим «мигал»: пожелание `auto` оставалось, хотя Claude уже был в `auto`.
- Карточка «Подтвердить выпуск» строилась только из итога хода автопилота сессии; при
  выключенном автопилоте сессии (после «стоп») её не было.

## Исправление по задачам

| Задача | Коммит | Что |
| --- | --- | --- |
| T001 | `21d9400c` | хост уступает сообщениям Remote Control (строка Ingress лога Claude), 3 с без обнаружения после ввода, меню без шага закрывается через 10 с, текст пользователя ждёт неубранный терминал (до 10 с), неудача обнаружения хранится в каталоге (`failed`), действующее пожелание снимается; уборка — по правилам M28 |
| T002 | `b08d5202` | `sendDirect` не вставляет в диалог, черновик или неубранный терминал (очередь); вставка подтверждается хуком `UserPromptSubmit` с тем же текстом до 8 с, иначе `{ sent: false, undelivered: { reason } }` |
| T003 | `9ecbf330` | панель: «Сообщение не дошло до Claude: <причина>», текст остаётся, «Повторить»; «Подтвердить выпуск» в проекте `host` без решения хода автопилота сессии |
| T004 | этот коммит | сквозные сценарии 19.11 и этот документ |
