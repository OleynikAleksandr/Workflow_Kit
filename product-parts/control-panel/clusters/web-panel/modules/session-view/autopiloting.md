# session-view: автопилотирование (M39)

## Автопилотирование (M39)

- Строка «Ревью плана: да/нет» убрана из сайдбара: слот `sessionReview` не регистрируется,
  настройка ревью — в «Настройки → Автопилотирование». Карточка «Ревью плана», замечания,
  повтор и журнал остаются. Под вопросом агента о плане сказано, что ответ — решение для
  этого задания.
- Часть `run` сайдбара (после выбора, перед планом) — `runCard`:
  - режим, этап и его признак;
  - причина ожидания (`wait.detail`: «Ждёт CI», «Ждёт ответа на вопрос агента») или
    остановки (`reason`; истёкший вопрос — «Нужны данные»), `nextAction`;
  - кнопки «Пауза», «Продолжить», «Остановить автопилот» (последняя — с `STOP_CONFIRM`) →
    `POST /api/projects/:id/autopiloting/pause|resume|stop { runId, expectedRevision }`
    ровно этого запуска;
  - после закрытия плана — «Публикует <sha> в <upstream>», затем «<sha> → <upstream> ·
    коммитов: N» (или «уже был на удалённой ветке, проверен»), либо «Публикация не
    выполнена: <причина>». Зелёным — только проверенная публикация.
  - M41: фаза `accepting` с `manualAcceptance` — «Ждёт вашей приёмки»
    (`USER_ACCEPTANCE_LABEL`), признак ожидания, причина и `nextAction` («нажмите «Принять
    план»…»), кнопки «Пауза» и «Остановить автопилот» (принимает карточка плана);
    `notice` запуска — строка-предупреждение (`RunView.notice`) без смены фазы, после
    `completed`/`stopped` не показывается.
  - M44 T004: запуск в фазе `executing`/`delivering` с `authorized: false` в сводке —
    «Автопилот не получил разрешения Kit» (`NO_GRANT_LABEL`), признак предупреждения,
    причина Kit (`reason`) или `NO_GRANT_DETAIL` («План идёт вручную…»), кнопки «Повторить»
    (основная, `POST /api/projects/:id/autopiloting/retry { runId, expectedRevision }`),
    «Пауза», «Остановить автопилот». Нет поля (старая служба) — прежняя подпись. Браузерная
    проверка — `test/m44-run-card.browser.mjs` (Chromium, обе темы, 1280 и 390 px).
  Остановленный или ждущий запуск зажигает `data-needs-attention`.
- `planView.autopilotingMode` — режим настроек, пока у плана есть кнопка старта.
  `policyLine` один раз на план и режим спрашивает `GET
  /api/projects/:id/autopiloting/policy` и показывает «Автопилот после старта: …»
  (legacy, ручная приёмка, «Обновите Kit проекта»), затем карточка перерисовывается.
- Тест — `test/run-model.test.ts`.
