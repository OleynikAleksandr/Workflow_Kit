- Спецификация: [M16-plan-start-after-review.md](../planning/M16-plan-start-after-review.md);
  scope `m16-plan-start-after-review`, режим `sequential`.
- Причина: живая проверка 0.8.2 на Windows (проект A007, Claude — агент, ChatGPT — ревьюер).

  программу для Windows.»; выпуск: «Да, с выпуском».

    учитывает только сессии, которые проект знает (опция `owns` — `ownsSession` cli).
  - T002 `a17bc4d` — панель: `reviewComing` не считает сессию, которой нет в списке сессий
    проекта у провайдера (без списка — прежнее поведение).
