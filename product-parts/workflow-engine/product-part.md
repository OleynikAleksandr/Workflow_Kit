# Часть продукта: workflow-engine

## Назначение

Процесс Harness Workflow Kit 2.2.3 в проектах пользователя (веха 2,
спецификация `docs/planning/M2-interface-and-process.md`): вендорный бандл
Kit, запуск его команд, кэш состояния плана и модели карточек плана и
выбора пути; цикл сессии — канал к агенту через хуки, автопилот, ревью
плана, имена сессий.

## Кластеры

| Кластер | Назначение |
| --- | --- |
| [kit-host](clusters/kit-host/cluster.md) | бандл Kit, запуск команд, слежение за планом, модели карточек |
| [session-loop](clusters/session-loop/cluster.md) | канал к агенту через хуки, автопилот и действия с планом, переключатель «Ревью плана», имена и архив сессий |

## Границы

- Kit не встраивается в код: команды выполняются отдельным процессом
  `node <bundle> …`, ответ читается из JSON-конверта Kit.
- Файлы среды Kit в проекте (`.harness/workflow/**`, план) не читаются и не
  пишутся напрямую — только командами Kit; служба лишь следит за
  изменениями файлов, чтобы вовремя спросить `status`.
- Не знает HTML панели: отдаёт модели (`PlanView`, `ChoiceCard`) через
  раздел `workflow` в `/api/state`; рисует их `control-panel`.
- Модули обращаются друг к другу только через `src/index.ts` (алиасы `#…`
  поля `imports` в `package.json`).
