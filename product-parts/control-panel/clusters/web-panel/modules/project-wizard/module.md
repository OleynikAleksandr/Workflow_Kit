# Модуль: project-wizard

Часть `control-panel`, кластер `web-panel`. Алиас импорта: `#project-wizard`.

## Назначение

Мастер проекта в панели (спецификация вехи 2, раздел 7; макет, шаги 3–5):
имя или папка → предпросмотр с действиями, изменениями и выборами →
«Создать и открыть в ChatGPT / Claude» (одно согласие) → шаги подготовки с
«Отменить подготовку» → чат первой сессии открывается сам на том
устройстве, где нажата кнопка.

## Публичный интерфейс для бэкенда (`src/index.ts`)

- `PROJECT_WIZARD_PREFIX` — `/project-wizard/`.
- `PROJECT_WIZARD_ASSETS_DIR` — абсолютный путь к `src/`.
- `projectWizardMount() → { prefix, dir }` — монтирование для
  `http-server` (подключает `cli`, `createApp`).

## Подключение к панели

`project-wizard.js` — расширение панели (`PANEL_EXTENSIONS` в
`panel-shell`): `install(shell)` заполняет слот `newProject`
(`registerSlot`); маршруты `#/new` и `#/open` показывают мастер. Из
оболочки берутся `api`, `ApiError`, `createFolderPicker`, `showError`,
`dom`. Стили — `project-wizard.css`.

## Файлы

| Файл | Содержание |
| --- | --- |
| `wizard-model.js` | чистые модели: `previewView(preview, now)` (заголовок, путь, действия, «Изменения в папке · N файлов», блокировка с командами, заметки, истёк ли токен), `choiceViews`, `validAnswers` (ответы только из вариантов), `buttonViews` (кнопки выключены с причиной: блокировка, провайдер недоступен, нет ответа на обязательный выбор), `findRun`, `runView` (заголовок, шаги с отметками ✓ / спиннер / ○ / – / ✕ и заметками, `canCancel`, ошибка с подсказкой, ключ созданной сессии), `chatTarget(links, maxTouchPoints)` (ссылка устройства: http(s) — в новой вкладке, ссылка приложения — на месте), `filesLabel`, `PROVIDERS`, `STEP_MARKS` |
| `project-wizard.js` | DOM мастера: шаг имени (`POST /api/setup/preview { mode: 'create', name }`, «Изменить расположение папки для проектов» ведёт в «Настройки») или выбор папки (`{ mode: 'open', path }`); предпросмотр с выборами (переключатели) и двумя кнопками (`POST /api/setup/apply { token, provider, choices }`; устаревший предпросмотр перезапрашивается сам с пояснением); подготовка из раздела `setup` (`POST /api/setup/:op/cancel`, «Повторить», «Закрыть»); после успеха — открыть чат (если браузер не дал — кнопка «Открыть чат») и перейти к сессии, когда она появится в дереве |
| `project-wizard.css` | выборы, список файлов, отметки шагов |

## Инварианты

- Чистая логика в `wizard-model.js` без DOM; покрыта `node --test`.
- До нажатия кнопки ничего не пишется: предпросмотр только читает.
- Текст в DOM — только через `textContent`.
