## Дефекты, найденные на шаге 2, и исправления (2026-11-06)

Проект H001, сессия ChatGPT `01a1b0dd-…`.

1. **В дереве появлялись лишние сессии** («Сессия 01a1b0de», позже
   «Сессия 01a1b0e8»). Причина: Codex Desktop открывает чат, созданный не им,
   и после хода запускает скрытый форк треда на один короткий ход.
   `SessionStart` форка приходит с `source: "fork"` без `transcript_path`, в
   ChatGPT он не виден. Исправление: `readHookSessions` пропускает такие форки
   (`isHelperFork`).
2. **Сессия не получила имя по задаче.** Агент выполнил
   `wfk session title "Склад: анализ остатков"`, служба отказала: «идут ходы
   нескольких сессий» (форк числился идущим ходом). Исправление: команда
   передаёт id своей сессии (`CODEX_THREAD_ID` / `CLAUDE_CODE_SESSION_ID`);
   без id служба выбирает из идущих ходов сессию из списка провайдера.
3. **Цель плана не доходила до панели как запасное имя.** Раздел `titles`
   содержит только сессии с файлом имени. Исправление: панель сама называет
   сессию-владельца плана его целью (`ownerObjective`).
4. **Первая сессия ChatGPT открывалась больше минуты** (H002: тред создан
   16:04:01, ход закончился 16:04:13, демон выгрузил тред лишь в 16:05:14).
   Причина: после хода демон Codex держит тред без подписчиков ещё 60 с, и
   мастер ждал эту минуту, иначе ChatGPT пишет «чат открыт в другом
   приложении». Claude этого шага не имеет, поэтому быстрый. Исправление:
   после завершённого хода служба вызывает `thread/archive` (демон
   выгружает тред сразу) и `thread/unarchive` (тред возвращается в списки,
   не загружаясь). Опыт на демоне: ход 4,4 с, тред выгружен в ту же
   секунду, файл переписки и имя на месте. Без `thread/archive` остаётся
   прежнее ожидание.
5. **Из «Настроек» нельзя было выйти** иначе как через «Создать проект».
   Исправление: шестерёнка на экране «Настройки» нажата и выводит из них,
   в шапке «Настроек» есть «✕»; оба ведут на экран, с которого их открыли
   (иначе на главный). Проверено в браузере: «Архив» → шестерёнка →
   «Настройки» → шестерёнка (или «✕») → «Архив».
6. **Панель открывалась окном Chromium**, своего значка в Dock не было.
   Исправление: `wfk install` на macOS собирает `Workflow Kit.app`
   (`swiftc`, ~5 с) — панель в собственном окне (WKWebView), значок в Dock
   можно закрепить. Картинка рисуется при установке из значков
   установленных Claude.app (левая половина) и ChatGPT.app (правая); в
   репозиторий логотипы не попадают. Без `swiftc` остаётся прежний значок
   с окном браузера и причиной в отчёте. Проверено: отчёт install —
   «приложение с окном панели», `wfk open` открывает приложение, его
   WebKit подключён к службе на 4747.
7. **Замечания к панели и мастеру** (A002, Claude):
   - в дереве теперь только выбранный проект, остальные — в меню «Ваши
     проекты»; стрелка меню смотрит вверх, пока оно открыто;
   - в «Настройках» карточка «Архив» с одной кнопкой; экран «Архив» по
     образцу Workflow Pilot — проекты и сессии в двух колонках, выбор
     щелчком, ⌘/Ctrl и Shift; проекты: «Вернуть в активные», «Убрать из
     списка» (папка остаётся), «Удалить с диска…» (только из архива, после
     ввода точного имени; домашняя папка и папка для проектов не
     удаляются); сессии: «Вернуть», «Убрать из списка» (чат в приложении
     остаётся);
   - карточки «Структура Kit», Claude и ChatGPT/Codex убраны из «Настроек»
     (модуль `provider-cards` удалён); «Запустить демон» и другие действия
     провайдера мастер показывает у выключенной кнопки провайдера;
   - вопроса «Внешние импорты CLAUDE.md» нет: импорты разрешаются по
     умолчанию (меняется в настройках Claude);
   - после подготовки нет кнопок «Открыть чат» и «Перейти к сессии»: чат
     открывается сам, панель переходит к сессии;
   - у всех кнопок три состояния: обычное, наведение, нажатие; нажатие
     держится 180 мс после отпускания, после щелчка — кольцо 0,45 с.
   Проверено в браузере: дерево с одним проектом, меню, «Настройки» →
   «Архив» (6 проектов), выбор диапазоном, панель удаления (кнопка
   включается только после точного имени, «Отмена»), вид нажатой кнопки.
   Ничего не удалялось.
