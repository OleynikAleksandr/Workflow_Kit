# Матрица ОС: M48 (автопилот и ревью сессии)

Часть [матрицы ОС](OS-MATRIX.md): строки вехи M48 ведутся здесь, чтобы основной документ
оставался в пределах размера. Правила те же: каждое изменение дополняет таблицу в том же коммите.

| Возможность | macOS | Linux | Windows |
| --- | --- | --- | --- |
| M48 T001: настройки автопилота сессии в `.workflow-kit/local/autopiloting/sessions/<client>.<id>.json`, Settings — значения для новых сессий, маршруты карточки сессии | общий `session-settings.ts` | то же | то же; имя без `:` (недопустимые знаки — `_`), путь через `path`, `writeJsonAtomic` с внедрённой платформой (временный файл, `rename` с повтором); ветки ОС нет, тест записи с `win32` |
| M48 T002: переключение автопилота сессии на любом этапе (этап задания, запуск `session-card`, захват начатого плана с `automation`, ответ на вопрос о плане с инструкцией полного запуска) | общий `session-switch.ts` | то же | то же; ветки ОС и программ ОС нет |
| M48 T003: ревью сессии — одно значение карточки и вопроса о плане, меняется до выбора способа, отмена идущего ревью | общие `session-review.ts` службы и `session-settings.ts` | то же | то же; ветки ОС и программ ОС нет |
| M48 T004: план без публикации завершается «результат локальный»; нажатие при `LOCKED` ждёт и применяется один раз | общие `run-complete.ts`, `kit-waits.ts` (таймер службы) | то же | то же; ветки ОС и программ ОС нет |
| M48 T005: карточка автопилота сессии, кнопки, которые нажимает идущий запуск, скрыты, итог локального запуска, строки ожидания Kit | браузерные ES-модули `session-view`, `panel-shell`; проверка Chromium Playwright | то же | то же; ветки ОС нет |
