# Параметры сессии и нативные контролы (M25–M26)

createParameters в composer владеет строкой, всплывающим меню/подсказками и своим
single-flight опросом GET …/sessions/:sid/parameters. Проверка видимости приходит
из существующего check карточки раз в секунду; HTTP — раз в 5 секунд, при открытии,
после отправки и изменения. Скрытая/отсоединённая карточка не опрашивается.
Поздний ответ прежнего поколения после POST игнорируется. Ошибка чтения сохраняет
последние значения, восстановление снимает её. supported false возвращает прежнюю
строку M24; Kimi и провайдеры без метода не меняются.

В строке — только inRow, в порядке items провайдера; tone, zap, ring first/last,
шрифт 14 px/400 из style.font. Шрифт и hex-цвет дуги проверяются чистой моделью,
затем ставятся через CSSOM. Кольцо, лимиты и причины доступны по нажатию;
контекст без источника не выдумывается. Лимиты отсутствуют без данных; от 80/95 %
используют warn/error токены темы. Время сброса в подсказке — местное.

Legacy-меню без presentation содержит все параметры, включая недоступный раздел без options с текущим
значением/reason. Варианты — menuitemradio с aria-checked; выбор отправляет один POST
{ change }, на время запроса варианты заблокированы. Вариант с confirm сначала
показывает локальное подтверждение; только «Продолжить» отправляет confirmed true.
Ошибка/hint — в sc-status под вводом; успех и notes не выводятся (уточнение M26/R2).

ArrowDown открывает меню с клавиатуры; стрелки, Home/End и Enter работают внутри,
Esc закрывает и возвращает фокус. Внешнее нажатие закрывает, Tab отпускает меню.
Постоянные элементы строки не отсоединяются при опросе, фокус сохраняется.
На coarse-pointer цели имеют высоту 44 px, кольцо также ширину 44 px.
Всплывающие элементы fixed в body, не меняют высоту карточки; ограничены visualViewport,
реагируют на его resize/scroll. Текст ставится через textContent/DOM, CSP не ослабляется.

parameters-model.js содержит URL, проверку стиля, подписи, пороги, модель меню и опроса;
покрыт node-тестами. Значки zap/chevron-down/check — локальные Lucide SVG с общей лицензией.

## Поведение на ОС и проверки

Браузерный код одинаков на macOS, Linux, Windows x64/ARM64. Изолированный Chromium на Mac
проверил пять размеров 1920×1080, 1280×800, 1024×768, 768×400, 375×667 в обеих темах;
сенсорные media queries, 640×400 CSS при DPR 2 (эквивалент уменьшенного viewport для 200 %),
меню/подсказки/подтверждение/ошибки/fallback/частичные каталоги/фокус и скрытую вкладку.
Артефакты — docs/evidence/M25/. Это не проверка нативного touch/экранной клавиатуры iPad
и не живая проверка Windows/Linux; она остаётся за исполнителями приёмки.

## Нативная презентация M26

presentation.layout=effort-card включает отдельные якоря. Composer размещает плюс
и accessNode слева, кольцо/модель/усилие справа, микрофон у края; permissions справа
не дублируются. Провайдеры без этой презентации сохраняют исходный DOM.

effort-card.js/effort-model.js: каталог поддерживаемых low/medium/high/xhigh/max/ultra,
preview во время drag и keyboard repeat, один POST по завершении. Esc/pointercancel
отменяют несохранённый жест. Polling сохраняет preview и фокус, неизвестное значение
не подменяется первым. Молния меняет priority/standard; подсказка из speedHint доступна
hover/focus/touch. Список моделей появляется отдельным поповером под editor; режим
остаётся в его компактном разделе. При недостатке места выбирается другая сторона.

access-menu.js: opaque options, описания/значки/disabled/reason из адаптера, стабильные
кнопки при polling. Полный доступ оранжевый, подтверждение до записи; cancel без POST.
Оба якоря и все меняющие controls заблокированы во время POST. Результат перечитывается.
Поповер доступа привязан слева к плашке, размеры ограничены visualViewport; меню
прокручивается при низкой высоте. Круговой стрелки и Подробнее нет по указанию пользователя.

parameters.css использует более специфичные native selectors и локальные маски Lucide;
нет inline HTML/SVG, сторонних загрузок или ослабления CSP. Молния — заполненный исходный
контур Lucide. Общая геометрия desktop: 255×97 / 644×162 CSS, radius18; touch — цели44.
Группа модели переносится целиком до сжатия, светлая/тёмная палитры читаемы.
Проверки трёх ОС — общий код и CI, живой iPad/Windows отдельно. Браузерное доказательство,
история исправлений и финальные снимки: [Design QA](../../../../../../design-qa.md).

## Исправления M26/R2

По замечаниям пользователя 13.11.2026 успешная смена параметров молчит:
нет зелёного «Параметры обновлены», технических notes policy/reviewer или прогресса.
Ошибки чтения/записи по-прежнему показываются; состояние видно прямо в контролах.

Явный pointer capture на input мешал захвату внутреннего thumb. Теперь capture
принадлежит родному range, а document pointerup завершает жест даже вне дорожки.
Только соответствующий pointerId может завершить/отменить жест; потеря capture,
pointercancel, blur окна и закрытие снимают listeners. Поздний change после отмены
не пишет значение. Polling не переписывает max/disabled без изменения значения.
Повторяемая browser-регрессия test/native-controls.browser.js использует настоящий
composer и изолированный provider I/O; desktop и touch-вариант, обе темы, ошибки,
клавиатура, cancel, held drag через polling. Это Chromium, не живая проверка Safari/iPad.
