# Параметры сессии ChatGPT (M25)

`Provider.readParameters(project, localId)` возвращает эффективные параметры по общему
контракту `provider-registry`. Чтение — одно соединение с демоном, `thread/read` без
ходов; без загрузки треда, `turn/start`, проверки общего доступа или внешних программ.
Модель и усилие — из ответа демона. `thread.path` читается через общий `createJsonlTail`:
новейшие настройки (`thread_settings_applied` или `turn_context`) и новейший `token_count`.
Параметры без источника отсутствуют; незнакомые значения показываются идентификаторами.
Отсутствие `service_tier` не считается стандартной скоростью.

Соединение параметров использует `experimentalApi: true`; отказ initialize даёт повтор
без флага: показ работает, варианты изменения отключены. Остальные соединения не меняются.
`initializeSession` и `CodexRuntime.withDaemon` получили необязательный флаг experimentalApi.

`model/list`, `collaborationMode/list`, `permissionProfile/list` кэшируются на 10 минут;
`account/rateLimits/read` — на 60 секунд. Незнакомая модель/усилие сбрасывают каталог модели;
`refresh` очищает все кэши параметров. Недоступный каталог не скрывает параметр:
у него нет options и есть reason. Варианты — только при сохранённом состоянии общего доступа
active/unsupported и записи настроек сессии; пустое состояние даёт причину «проверяется».
Просроченный снимок общего доступа не проверяется заново во время чтения.

Порядок: скорость (молния только priority), модель, усилие, разрешения, режим (в строке
только «План»). Названия модели нормализуются только по displayName каталога;
неизвестный id не переписывается. Шрифт — стек системного шрифта ChatGPT, кольцо — слева.
Контекст — last_token_usage.total_tokens / model_context_window; процент ограничен 0–100.
Лимиты primary/secondary: подпись по длительности окна, resetsAt — ISO; политика одобрений
показана в notes. readParameters не меняет настройки и ничего не одобряет.

Стандартные разрешения распознаются только по проверенным структурам из раздела 4 правил
M25: disabled; managed с restricted-сетью и единственным read-корнем; managed workspace
с записью только в runtime_workspace_roots и slash_tmp/tmpdir, с дополнительным чтением
только внутри рабочих папок. Иное — «Особые разрешения», value null. Из turn_context
распознаются только read-only/danger-full-access. В меню полный доступ содержит confirm.

`createParameterParts` — публичная фабрика для внедрения в провайдера и проверки живого
чтения. Тесты заменяют runtime и RPC; проверяют отсутствие запуска программ, загрузки треда
и перепроверки общего доступа, кэши, подписи, ограничения каталогов и распознавание профилей.

## Поведение на ОС

| macOS | Linux | Windows x64/ARM64 |
| --- | --- | --- |
| Unix WebSocket демона, файл по thread.path | тот же демон; общий доступ unsupported | существующий proxy, файл по thread.path |

Платформа внедряется в runtime и распознавание путей разрешений. Новых программ ОС нет.
Живое чтение проверено на macOS; Windows — проверяющий на Windows, Linux — CI.
