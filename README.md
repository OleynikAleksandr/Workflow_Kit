# Workflow Kit

Workflow Kit — локальное приложение для управления проектами и работой агентов
в **Claude, ChatGPT/Codex и Kimi Code**. Агенты работают в приложениях провайдеров; Kit ведёт
проекты, сессии, планы, ревью и процесс выполнения и показывает диалог каждой сессии:
читать переписку и писать агенту можно прямо в панели.

**Текущая версия: 0.12.1.** macOS, Windows 11 (x64 и ARM64) и Linux; что проверено
вживую на каждой ОС — в [поддержке ОС](docs/installation.md#поддержка-ос).

## Как это работает

Один процесс Node.js запускает бэкенд, HTTP API и раздаёт веб-панель.
Панель открывается по адресу [http://127.0.0.1:4747/](http://127.0.0.1:4747/).
После установки процесс работает в фоне и запускается при входе пользователя.
Закрытие окна панели не останавливает службу.

Kit использует локальные программы Claude Code, Codex и Kimi Code. Сессии открываются
в родных приложениях, а инструкции процесса передаются агентам через хуки.
В управляемые проекты устанавливается Harness Workflow Kit 2.2.4 — его исходники лежат в этом
репозитории (`product-parts/kit-core`), бандл собирается здесь же. Пакет восстановления
приходит агенту целиком при старте сессии — Claude частями (шесть хуков), ChatGPT одним
хуком с поднятым лимитом; хуки ChatGPT Kit подтверждает сам.

Основные возможности:

- Создание и подключение проектов, подготовка папки и первая сессия через мастер.
- Версия Kit на экране проекта; устаревший Kit обновляется кнопкой «Обновить Kit» — без
  мастера, без новой сессии и без подтверждений хуков ChatGPT.
- Выбор Claude, ChatGPT/Codex или Kimi Code для сессии, имена, архивирование и открытие чатов.
- Спецификация и план, последовательное выполнение или встроенные подагенты провайдера.
- Перекрёстное ревью плана: Claude проверяет план ChatGPT и наоборот, план Kimi проверяет ChatGPT;
  служба пересылает замечания и ответы, панель показывает ход и журнал ревью.
- ChatGPT на macOS и Windows: общий доступ к чатам — Kit, ChatGPT на компьютере, iPad и
  телефон работают с одним чатом, включая чат ревьюера
  ([настройка](docs/setup.md#шаг-4-chatgpt-codex)).
- **Диалог с агентом в панели** (с 0.9.0): переписка любой сессии Claude, ChatGPT и Kimi и
  поле ввода — см. [«Диалог с агентом»](docs/usage.md#диалог-с-агентом).
- Автопилот задач с остановками для пользовательских решений, выпуска и приёмки.
- Публикация на GitHub — отдельное действие после приёмки и закрытия плана.
- Веб-панель на компьютере (macOS, Windows, Linux) и удалённо на iPad/телефоне через Tailscale.

Это приложение для локального компьютера: для удалённой работы компьютер со службой должен
быть включён и доступен.

## Установка

Нужны Node.js, Git и хотя бы один провайдер — программа командной строки и приложение
(Claude, ChatGPT/Codex или Kimi Code), вход выполнен в обоих. **Сначала ставятся программы
провайдеров, потом Workflow Kit.** Затем:

```sh
git clone https://github.com/OleynikAleksandr/Workflow_Kit.git
cd Workflow_Kit
node bin/wfk.mjs install
wfk doctor --installed
```

Установщик копирует приложение, создаёт команду `wfk`, значок **Workflow Kit** и автозапуск
при входе в систему и запускает службу. Панель открывается значком или командой `wfk open`.

- [Установка шаг за шагом](docs/setup.md) — для новичка: терминал, Node.js и Git, Claude,
  ChatGPT, Kimi Code, проверка программ, панель на iPad и телефоне, частые ошибки.
- [Руководство по установке](docs/installation.md) — требования, что создаётся в каждой ОС,
  общий доступ к чатам ChatGPT, удалённый доступ, обновление, удаление и диагностика.

## Работа с проектом

1. В панели откройте мастер проекта, выберите папку и провайдера первой сессии; Kit
   подготовит проект и откроет сессию в приложении провайдера.
2. Опишите задачу агенту. Для разработки он спросит решение: план с ревью, без ревью или
   «Просто обсуждаем».
3. Выберите режим выполнения и запустите план в панели; следите за задачами, подтверждайте
   выпуск и принимайте результат. Закрытие плана и публикация на GitHub — отдельные действия.

**Диалог с агентом.** На экране сессии в панели — карточка «Диалог»: переписка сессии и
поле ввода. Ждущему агенту сообщение приходит сразу вашей репликой (Claude — в сессии,
которую ведёт панель, ChatGPT — при общем доступе к чатам), иначе ждёт в очереди до конца
хода агента или вашего следующего сообщения в чате.

**Интерфейс 0.10.0 (M24).** План и карточки решений перенесены
под дерево проектов слева; ширина сайдбара меняется, диалог прокручивается внутри окна.
Ввод показывает Enter при ожидании и Stop во время работы; очередь доступна через
Ctrl/⌘+Enter и «В очередь». Stop сохраняет черновик/очередь и удерживает автоматическое
продолжение; доступность зависит от управляемой сессии провайдера. Плюс и микрофон пока
отключены, параметры показывают только имеющиеся данные. Реализация и автоматические
проверки завершены; локальная поставка подготовлена, живая приёмка ещё впереди —
[результаты и ограничения M24](docs/evidence/M24-acceptance.md).

Подробно — [работа с Workflow Kit](docs/usage.md): первый проект по шагам,
[диалог с агентом](docs/usage.md#диалог-с-агентом) и
[особенности провайдеров](docs/usage.md#особенности-провайдеров-в-работе).

**Параметры сессий 0.11.0 (M25).** Под вводом видны фактические модель, усилие,
режим, контекст и лимиты Claude/ChatGPT. Параметры ChatGPT меняются из меню;
полный доступ требует подтверждения. Для Claude данные контекста собираются
со следующего запуска или возобновления панелью; пользовательская строка состояния
сохраняется. Kimi показывает прежнюю строку. Установлена локальная поставка;
статус CI и отдельной живой приёмки — в [доказательствах M25](docs/evidence/M25-acceptance.md).

**Нативные контролы M26.** Карточка усилия с ползунком и молнией скорости,
отдельный список моделей и отдельная плашка доступа у плюса заменяют общий длинный
список ChatGPT. Пресеты используют штатную проверку Codex; полный доступ требует
подтверждения. Сброс и «Подробнее» исключены по согласованию. Браузерные проверки
и сравнение с эталонами завершены — [Design QA](design-qa.md),
[результаты M26](docs/evidence/M26-native-controls.md). Локальная 0.12.0 установлена;
CI точного SHA и пользовательская живая приёмка учитываются отдельно.

**Исправления M26/R2.** Бегунок усилия захватывается и перетаскивается мышью;
служебный зелёный подстрочник после смены параметров убран. Ошибки остаются видимыми.
Подробности — [результаты R2](docs/evidence/M26-native-controls.md#r2--t008-замечания-пользователя-после-0120).
Исправления установлены в локальной 0.12.1; CI и живая приёмка фиксируются отдельно.

**Контролы Claude M27 (исходники следующей 0.13.0).** В управляемой беседе можно
выбирать модель, Effort и отдельный Ultracode через вложенные меню, а Auto/Manual/
Accept edits/Plan — отдельной кнопкой Mode, как в Claude Desktop. Нужны Claude
2.1.323+ и новый запуск/штатное возобновление панелью; старые и внешние host остаются
для чтения с причиной. Изменения действуют только в этой беседе и не меняют defaults.
Скорость доступна только при нативном разрешении аккаунта; в проверенном аккаунте
fast требует usage credits и не включается. Native roundtrip и визуальная проверка
завершены — [результаты M27](docs/evidence/M27-claude-native-controls.md),
[Design QA](design-qa.md). Сборка/установка 0.13.0 и CI — следующие этапы плана.

## Запуск из исходников и разработка

`node bin/wfk.mjs serve` запускает сервер из репозитория без установки; `npm ci`,
`npm run typecheck`, `npm test` и `npm run check:platforms` — проверки разработки;
`npm run build:kit` собирает бандл Kit из `product-parts/kit-core`. Подробно —
[руководство](docs/installation.md#запуск-из-исходников-и-разработка), правила — [AGENTS.md](AGENTS.md).
