# Кластер: control-panel / web-panel

## Назначение

Веб-панель: каркас страницы с шапкой (версия, ОС, состояние связи), реестр
карточек и сами карточки — «Система», проекты, структура, провайдеры.

## Модули

| Модуль | Обязанность | Задача |
| --- | --- | --- |
| [panel-shell](modules/panel-shell/module.md) | каркас панели, опрос состояния, реестр карточек, «Система», проекты, структура | T001–T003 |
| `provider-cards` | карточки провайдеров из контракта | T005 |

## Границы

- Файлы модуля лежат в его `src/` и отдаются сервером как есть (без сборки).
- Карточки других модулей подключаются через реестр карточек
  `panel-shell` (`registerCard`); каталог `provider-cards` будет смонтирован
  сервером под своим префиксом.
- Состояние только читается из `GET /api/state`; действия — через POST с
  `Content-Type: application/json` (Origin браузер ставит сам).
