# M39: Settings и состояние в панели

Часть [спецификации M39](M39-autopiloting.md).

## 2. Settings и состояние в панели

Порядок карточек: «Внешний вид», «Автопилотирование», «Архив», «Система»,
«Общий доступ к чатам ChatGPT». Новая карточка открыта, режимы и ревью видны сразу.
Переключатель ревью уходит из боковой панели сессии; карточка результата ревью, замечания,
повтор после ошибки и журнал там остаются. Отображается фактическое ревью данного запуска,
а не только глобальная настройка. В старой карточке вопроса выбора `review|plan|talk`
явный ответ продолжает переопределять настройку этого запуска; под ним понятно написано,
что это решение для текущего задания.

«Система» и «Общий доступ к чатам ChatGPT» — две самостоятельные карточки, изначально
закрыты. В закрытом виде видны заголовок и стрелка. Нажатие на строку, Enter или Space
раскрывает содержимое; `aria-expanded` соответствует состоянию, скрытые контролы не
попадают в Tab. Можно использовать нативные `details/summary`. Радиус, граница, фон,
отступы и светлая/тёмная тема используют существующие токены `.panel`. Вложенная служебная
разметка не создаёт второй прямоугольной карточки. Сворачивание ничего не меняет в доступе
к ChatGPT. Опрос `/api/state` и переходы внутри текущего экземпляра панели не схлопывают
открытую пользователем карточку; после полной перезагрузки они снова закрыты.

Настройки сохраняются атомарно; пока запрос выполняется, виден статус записи. Ошибка
возвращает фактическое значение и короткую причину. Старый ответ сервера не перезаписывает
более новое решение с другого устройства: применяется ревизия настроек.

До ручного start карточка показывает effective policy и точку ручной остановки для
старого плана/manual criteria по [контракту управления](M39-autopiloting-controls.md).
Настройка after-start не маскирует отсутствие automation или поддержки Kit.

На карточке проекта/плана: выбранный режим, текущий этап, задача N/M, причина ожидания,
«Пауза»/«Продолжить»/«Остановить автопилот». Остановка автопилота отзывает полномочия
и останавливает новые автоматические действия, но сохраняет план для ручного продолжения.
Кнопка остановки ответа сохраняет немедленное прерывание провайдера по M24.
После закрытия план не пропадает вместе с ходом автопилота: карточка завершения показывает
«Публикует», затем SHA, upstream и число опубликованных коммитов либо причину отказа.
