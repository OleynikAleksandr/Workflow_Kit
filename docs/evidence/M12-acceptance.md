## Известные риски (**П**)

- Схема опирается на недокументированное поведение ChatGPT (`CODEX_SSH_SKIP_APP_SERVER_BOOT`,
  запуск `$SHELL -l -i -c`, обнаружение `Host` из `~/.ssh/config`); обновление приложения
  может её сломать — тогда карточка покажет «Не работает», а сессии вернутся к прежнему пути.
- Приложение ChatGPT при своём перезапуске может завершить процессы `codex … app-server
  --listen` (в его коде есть такой `pkill`), включая демон Kit; служба поднимает демон снова.
- Локальная копия чата из «Недавних» (без глобуса) только для чтения; открывать чаты нужно из
  Kit.
- Если ChatGPT запустился раньше демона, удалённое управление держит приложение: iPad не
  откроет чат Kit, пока ChatGPT не перезапустить (панель об этом говорит).
- Вид карточки в живой панели: модель покрыта тестами, DOM — нет.
