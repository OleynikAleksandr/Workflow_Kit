# Кластер: backend-core / runtime

## Назначение

Запуск процесса Workflow Kit и его данные: точка входа `bin/wfk.mjs`,
команды `wfk`, сборка бэкенда из модулей, каталоги данных по ОС, конфиг,
атомарная запись JSON, журнал событий, мьютексы и операции (D10).

## Модули

| Модуль | Обязанность |
| --- | --- |
| [cli](modules/cli/module.md) | `bin/wfk.mjs`, маршрутизация команд (`serve`, `link`, `hook`; команды службы передаются `service-installer`), `createApp` (сборка приложения), раздел `system` |
| [data-store](modules/data-store/module.md) | каталоги по ОС (0700), `config.json`, атомарная запись, журнал, мьютексы, операции |

## Границы

- `cli` — единственный модуль, который знает обо всех остальных: он
  собирает приложение и регистрирует маршруты и разделы состояния модулей.
- `data-store` не зависит от других модулей и не знает об HTTP.
- Переменные `WFK_DATA_DIR` и `WFK_PORT` читаются только здесь (через
  `data-store`), остальные модули получают готовые каталоги и конфиг.
