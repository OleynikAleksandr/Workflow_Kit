# M30: без служебных строк в ленте Claude Desktop

## Цель и согласование

В 0.13.3 модель и усилие Claude меняются из диалога Workflow Kit, но в ленту той же беседы
в Claude Desktop попадают служебные записи хоста:

- `/effort` → `Cancelled` — хост открывал меню усилия, чтобы прочитать варианты, и закрывал
  его Esc (первое чтение каталога и первый переход на модель с неизвестными вариантами);
- `/effort` → `Set effort level to high (this session only)…` — само изменение усилия;
- `Kept model as Opus 5.5` — хост закрыл меню модели Esc после чтения каталога.

Смена модели (`/model` и `s`) в ленте Desktop не видна.

Пользователь, 14.11.2026, тестируя 0.13.3: «Нельзя никак этот нюанс исправить, чтобы в
диалоге на десктопе не появлялись эти слэш-команды?» Затем: «Ну да, открывай новый скоп,
создавай план и выполняй его.»

## 1. Факты (проба 14.11.2026, Claude Code 2.1.325)

Одноразовый проект, Haiku 5.5; записи переписки после каждого действия:

| Действие | Запись в переписке | В ленте Desktop |
| --- | --- | --- |
| `/model`, `s` | user: `/model` → «Set model to `X` for this session only» | не видна |
| `/model`, ←/→, `s` | user: `/model` → «Set model to `X` for this session only with `low` effort» | не видна |
| `/model`, Esc | system `local_command`: «Kept model as `X`» | видна |
| `/effort`, Esc | user: `/effort` → «Cancelled» | видна |
| `/effort`, `s` | user: `/effort` → «Set effort level to …» | видна |

Меню `/model` показывает строку усилия: `○ Low effort ←/→ to adjust`, `◐ Medium effort
(default) ←/→ to adjust`, `● High effort`, `◉ xHigh effort`, `◈ Max effort`.

- Стрелки ←/→ меняют уровень и упираются в края (Low и Max), по кругу не идут.
- «(default)» помечает рекомендованный уровень модели.
- Строка показывает уровень сессии при открытии меню; при переходе по строкам моделей
  выбранный уровень сохраняется.
- У строки «More models» и у Haiku 4.5 строки усилия нет.
- Esc отменяет выбранный уровень. `s` без изменения уровня пишет подтверждение без «with … effort».
- На экране подтверждение: «Set model to Haiku 5.5 for this session only with low effort».

## 2. Принципы

- Модель и усилие — только для этой беседы, клавишей `s`; умолчания пользователя
  (`~/.claude/settings.json`) не меняются (M27, M29).
- Контракты M29 сохраняются: файл желаемых значений, `pending`, `failures`, кэш каталога,
  порядок полей, повторы, подтверждение модели строкой Claude, темп хоста.
- Хост не открывает `/effort` и не закрывает `/model` клавишей Esc в обычной работе.

## 3. Решение (provider-claude)

### 3.1. Экран (`parameter-screen.ts`)

- Кадр `model` получает `effortLevel` (`low|medium|high|xhigh|max|null`, «xHigh» → `xhigh`) и
  `effortDefault` (есть пометка «(default)»). Нет строки усилия — `effortLevel: null`.
- `freshAck` для усилия принимает и «Set effort level to <уровень>», и «Set model to … for
  this session only with <уровень> effort».

### 3.2. Движок (`parameter-engine.ts`)

- **Варианты усилия** читаются в меню `/model` на строке текущей модели (отмечена ✔): ←
  до упора, затем → до упора, с записью уровней и пометки «(default)»; уровень
  возвращается к исходному, меню закрывается `s`. Нет строки усилия — у модели нет выбора
  усилия (`values: []`), это знание тоже кэшируется.
- **Каталог**: после обхода моделей хост возвращается на строку ✔, читает варианты усилия и
  закрывает меню `s`. Нет строки ✔ (текущая модель вне списка) — прежний выход Esc.
- **Смена усилия**: `/model`, на строке текущей модели ←/→ до цели, `s`. Подтверждение —
  строка «… with <уровень> effort» и уровень в statusline.
- **Смена модели**: короткий путь M29 к строке цели; если варианты усилия этой модели
  неизвестны — тот же перебор ←/→ на строке цели и возврат уровня; затем `s`, диалог
  «Switch model?» и подтверждение, как в M29. Отдельного чтения после смены нет.
- **Ultracode** по-прежнему включается и выключается `/effort ultracode [off]`: другой
  команды в Claude нет, эта запись остаётся видна в ленте, но только по явному выбору
  пользователя. Доступность Ultracode больше не читается из `/effort`: известная из кэша
  сохраняется, иначе он доступен у моделей со строкой усилия; отказ Claude — строка
  `failures`.
- **Отмена** транзакции внутри `/model` (ввод пользователя, начало хода) по-прежнему
  закрывает меню Esc; запись «Kept model as …» тогда возможна.

### 3.3. Служба (`parameter-controls.ts`)

- Модель с известным пустым списком усилия: меню усилия без вариантов, причина «У этой
  модели нет выбора усилия» вместо «Варианты усилия появятся…».

## 4. Поведение на ОС

| Что | macOS | Linux | Windows |
| --- | --- | --- | --- |
| Усилие через меню `/model`, выход клавишей `s` | expect-хост | expect-хост, injected linux | ConPTY, те же клавиши `NATIVE_KEYS`; x64 и ARM64 |
| Причина для модели без усилия | общий Node-код | то же | то же |

Поведение одинаково на всех ОС: клавиши и кадры Claude общие, меняется только движок.

## 5. Проверка

- Тесты движка на кадрах 2.1.325: чтение уровней с упором и «(default)», возврат уровня и
  выход `s`; смена усилия без `/effort`; смена модели с чтением уровней на строке цели;
  модель без строки усилия; каталог без строки ✔ — выход Esc; отмена внутри `/model`.
- Живая проверка на macOS (одноразовый проект, Haiku, не больше двух коротких ходов):
  - после чтения каталога, смены усилия и смены модели в переписке нет записей `/effort`
    и «Kept model as»;
  - изменение подтверждается до 3 с;
  - хэш `~/.claude/settings.json` не меняется.
- Лента Claude Desktop — пользователь на 0.13.4. Windows — проверяющий на Windows.
  Linux — CI.
- CI: macOS, Linux, Windows x64 и ARM64 для точного SHA поставки.

## 6. Границы

- Не входит: скрыть `/effort ultracode` (другой команды нет); запись «Kept model as» при
  отмене транзакции; сессии хостов 0.13.3 и старше до возобновления панелью.
- Statusline сессий, запущенных под удалёнными версиями, — отдельная задача.

## 8. Итог реализации (DOCS-R1)

- T001: кадр `model` читает строку усилия и ✔ модели сессии; навигация по меню вынесена в
  `parameter-menu.ts` (`seekRow`, `effortLevels`), шаг клавиши `quiet` (400 мс) для края строки.
- Отличие от 3.2: неизвестные уровни новой модели читает не смена модели, а фоновое
  обнаружение сразу после неё (`/model`, уровни, `s`). Так смена модели укладывается в 3 с;
  запись тоже `/model` и в ленте Desktop не видна.
- T002: причина «У этой модели нет выбора усилия» (`NO_EFFORTS`); Ultracode у такой модели
  недоступен.
- T003, живая проверка (Haiku, один ход): записей `/effort` — 0, «Kept model as» — 0; усилие
  2,4–2,6 с, модель 2,6 с, режим 1,1–1,8 с; `~/.claude/settings.json` не изменился —
  [доказательства](../evidence/M30-claude-feed-quiet.md).
