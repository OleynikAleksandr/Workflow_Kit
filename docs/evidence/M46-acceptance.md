# M46: доказательства — меню `/model` Claude 2.1.328 и сообщения без мёртвой очереди

Спецификация — [M46-claude-2-1-328-menu.md](../planning/M46-claude-2-1-328-menu.md). План выполняется
под живым запуском автопилота `run-2dURYOtIflz8` (полный, Kit 2.4.6).

## Причина (19.11.2026, проект S_001, 0.20.1, Claude 2.1.328)

- Пользователь выбрал в панели Extra; хост параметров набрал `/model`, но меню 2.1.328 не узнал: его
  нижняя строка — `s to use this session only · Enter to save · Esc to cancel`, а разбор ждал строку
  2.1.325 `Enter to set as default · …`. Кадр стал чужим окном (`dialog`), хост отменил транзакцию и
  по правилам M28 меню не закрыл — терминал остался в меню.
- Сообщение панели: `claude: message to ca86002c… not pasted: the terminal is not free (Терминал
  Claude занят или не распознан)` — по M45 оно ушло в очередь ждущей сессии, которую хуки не
  заберут; панель через 10 с показала строку M28, пузырь «в очереди» остался.
- Воспроизведено на живом Claude 2.1.328 во временной папке (pty 160×40, те же клавиши хоста):
  записаны меню, строка `More models`, раскрытый список с `↓ 4 more`, прокрутка до `↑ 4 more`,
  модель без уровня (`○ Effort not supported for Haiku 4.5`), ответ на `s` (`Set model to Opus 5.5
  for this session only with high effort`). `~/.claude/settings.json` сохранён и после проверки
  совпадает байт в байт. Тот же разбор обрывал каталог на 10-й модели: прокрутка 2.1.328 — `↓ N more`.

- `npm run typecheck` — ok; `npm run test:app` — 1483 теста, 1481 прошли, 0 упали, 2 пропущены;
  `npm run test:kit` — 78 из 78; `npm run check:platforms` — `platform-guard: ok`.
- `provider-claude/test/m46-menu.test.ts` — записанные кадры 2.1.328 (меню, `More models`, `↓ 4 more`,
  конец списка, модель без уровня), кадр 2.1.325, чужое окно; чтение каталога (13 моделей, уровни) и
  смена уровня на имитации 2.1.328 (`test/claude-2-1-328.ts`) — пустое поле, `Enter` на модели не

  при открытом меню хоста — хост закрывает меню (`Kept model as Opus 5.5`) и текст идёт в пустое

  `{ refused: <причина> }`, текст не вставлен.
- `agent-channel/test/m46-direct-refused.test.ts`, `cli/test/m46-direct-refused.test.ts` — отказ даёт
  `undelivered` с причиной (пустая — общая), очередь пуста, строка журнала `channel: message to
  <key> refused, not queued: <причина>`; `false` — очередь, как раньше.
- `cli/test/m46-refused-e2e.test.ts` — настоящая служба на loopback и хуки CLI: несвободный терминал —
  `{ sent: false, undelivered }` сразу (без ожидания хука), очередь пуста, ход не записан; после
  освобождения тот же текст — `{ sent: true }`.
