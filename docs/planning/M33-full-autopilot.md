# M33: совместимость с полным автопилотом

Дополнение к разделу 5 [спецификации M33](M33-agent-questions.md).

## Будущий сценарий и что из M33 ему служит

Пользователь, 15.11.2026: в дальнейшем будет сценарий полного автопилота — кнопка в
Settings, которую пользователь включает осознанно. Тогда пользователь обсуждает задачу
только в начале, а готовый результат получает без единого вопроса (уведомление на телефон);
кнопка не нажата — всё как сейчас. M33 полный автопилот не делает, но ему не противоречит:

- Один путь ответа: `answerQuestion` с журналом попыток не зависит от того, кто выбрал ответ.
  Будущий полный автопилот сможет ответить тем же путём (однократная передача, перезапуск,
  гонка с приложением — уже решены), записав свой источник ответа.
- Канал Claude (хук `PermissionRequest`) и слушатель Codex отвечают за пользователя только
  по вызову `answerQuestion`; другого кода ответа в M33 нет, его не придётся обходить.
- Ни одно соединение Kit не отвечает на запросы сервера ошибкой: отказ по умолчанию не
  отменит вопрос, который полный автопилот собирается решить.
- Карточка, `answerable`, причины и ограничения (секретный ответ, вопрос сверх пределов) —
  данные, по которым автопилот решает, может ли он ответить сам или должен отложить работу.
- Чего M33 не решает: кто и как выбирает ответ при полном автопилоте, что делать с
  одобрениями и секретными вопросами, долгое ожидание хука при отсутствии пользователя.
  Это — задача будущей вехи.
