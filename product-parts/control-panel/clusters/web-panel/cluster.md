# Кластер: control-panel / web-panel

## Назначение

Веб-панель: каркас страницы с шапкой (версия, ОС, состояние связи), реестр
карточек и сами карточки — «Система», проекты, структура, провайдеры.

## Модули

| Модуль | Обязанность |
| --- | --- |
| [panel-shell](modules/panel-shell/module.md) | каркас панели, опрос состояния, реестр карточек, «Система», проекты, структура |
| [provider-cards](modules/provider-cards/module.md) | карточки провайдеров из контракта и операций |

## Границы

- Файлы модуля лежат в его `src/` и отдаются сервером как есть (без сборки).
- Карточки других модулей подключаются как расширения панели
  (`PANEL_EXTENSIONS`, `install(shell)`) через реестр карточек
  `panel-shell` (`registerCard`, `registerCardGroup`); каталог
  `provider-cards` смонтирован сервером под префиксом `/provider-cards/`.
- Состояние только читается из `GET /api/state`; действия — через POST с
  `Content-Type: application/json` (Origin браузер ставит сам).
