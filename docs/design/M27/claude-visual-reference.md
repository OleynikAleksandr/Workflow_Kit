# M27: нативный визуальный эталон Claude

## Визуальный контракт (заполняет T001)

Статус: PENDING. Обязательный context T005 и T006, должен быть заполнен до T001 DONE.
Основная поверхность: Claude Desktop, вкладка Code, Remote Control-представление
собственной тестовой беседы Kit, тёмная тема. Desktop-local и terminal TUI — только
семантика; нельзя подменить ими этот визуальный эталон без решения пользователя.

После дешёвой проверки канала/defaults/hooks T001 запрашивает недоступные read-only
наблюдению снимки пользователя. Нужны: (1) composer целиком, (2) меню модели,
(3) усилие, включая ultra/Ultracode, (4) скорость и предупреждение о расходе,
(5) режим доступа, (6) доступный пример disabled с причиной. Если отдельного меню
нет, зафиксировать реальный native сценарий, не придумывать такой popup.
Для обратной смены пользователь изменяет один параметр этой же пробной беседы
в Claude; T001 сверяет новую настройку, identity и read-back в Kit.

Обязательны тёмные native PNG. Светлые пользователь может дать при наличии; без них
светлая Kit проверяется по согласованным токенам, контрасту и раскладке и не называется
pixel match native. T001 может ждать этих действий несколько ходов; отсутствие
ответа не является ни согласием, ни успешным выполнением. До канального proof
не просить пользователя делать весь набор снимков. Не получены обязательные PNG —
task:block без commit T001; продолжение после решения пользователя.

T005 повторяет layout/порядок действий именно из заполненного контракта. Из одного
raw ultra не выводится вид отдельного toggle или шестой позиции. Противоречие
native state, каталога и UI — блокер до реализации, а не свободный выбор дизайна.
T006 сравнивает PNG и рендер в одном input при совпадающих состоянии, теме и плотности,
по размеру компонента эталона. Пять размеров окна — отдельная проверка раскладки
Kit: 1920×1080, 1280×800, 1024×768, 768×400, 375×667; не растягивать native PNG под них.
Эмуляция touch/200%/экранной клавиатуры явно отделена от живой macOS/iPad/Windows.
