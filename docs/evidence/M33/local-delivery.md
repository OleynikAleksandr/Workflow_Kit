через HTTP службы: открытие папки, структура Kit (версия 3), доверие Claude и Codex, одобрение

  `wfk hook question --client claude`.
- **Claude.** Новая сессия панели в обновлённом проекте; модель переключена на Haiku 5.5 с
  низким усилием параметрами панели (только для этой беседы). Вопрос отправлен из поля ввода
