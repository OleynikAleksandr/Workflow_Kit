# Часть продукта: backend-core

## Назначение

Ядро бэкенда Workflow Kit: точка входа `wfk`, данные на диске, HTTP API с
фильтром доступа и реестр проектов со структурой Kit в папке проекта.
Работает одинаково на macOS, Linux и Windows (Node 24, без runtime-зависимостей).

## Кластеры

| Кластер | Назначение |
| --- | --- |
| [runtime](clusters/runtime/cluster.md) | запуск процесса, команды `wfk`, сборка приложения, каталоги данных, конфиг, атомарная запись, журнал событий, операции |
| [http-api](clusters/http-api/cluster.md) | HTTP-сервер, фильтр доступа (D8), реестр маршрутов, раздача панели |
| [projects](clusters/projects/cluster.md) | реестр проектов и структура Kit в папке проекта |

## Границы

- Не знает деталей провайдеров: они подключаются через `provider-runtime`
  (свои маршруты и разделы состояния регистрируются в реестрах `http-api`).
- Не содержит HTML/CSS/JS панели: файлы панели живут в `control-panel`,
  бэкенд только отдаёт их.
- Не устанавливает службу и автозапуск: это `system-service`; `cli`
  передаёт команды службы в `runServiceCommand` и получает статус службы
  через `getServiceStatus` модуля `service-installer`.
- Модули обращаются друг к другу только через `src/index.ts` (алиасы `#…`
  поля `imports` в `package.json`).
