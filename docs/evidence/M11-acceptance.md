# Приёмка M11 — запуск плана с видимым ходом, релиз 0.6.4 (2026-11-10)

- Спецификация: [M11-plan-start.md](../planning/M11-plan-start.md); scope `m11-plan-start`,
  режим `sequential`.
- Причина: кнопка «Начать выполнение плана» исчезала только после первой команды Kit агента
  (`task:start` или `assignment:create`). Сессия Kimi перед этим долго готовится, и кнопка
  оставалась, хотя агент уже работал. Повторное нажатие отправляло второе стартовое
  сообщение.
- Что сделано:
  - T001 `34db53a` — состояние запуска в автопилоте (`start.ts`): ступени `sending` и
    `delivered`, признак `slow`, проблемы `not-delivered` и `turn-ended`, повторный старт без
    второго сообщения; в канале — `waiting(key, id)` и `UNDELIVERED_NOTE`.
  - T002 `2bcab73` — карточка плана: спиннер «Запускаю план» со ступенью и таймером сразу по
    нажатию, «План запускается», проблема и «Начать заново».
  - DOCS `e83aa43` — README и итоги раунда.
- Локально (macOS): `npm test` — 586 тестов, 585 прошли, 1 пропущен (не для macOS); проверка
  типов и `check:platforms` — ok; `node bin/wfk.mjs install` (обновление с 0.6.3) и
  `wfk doctor --installed` — «всё в порядке», служба 0.6.4.
