## Известные риски (**П**)

- Схема на Windows не подтверждена пробой; она опирается на то же недокументированное
  поведение ChatGPT, что и на macOS (`CODEX_SSH_SKIP_APP_SERVER_BOOT`, `$SHELL -l -i -c`), и на
  то, что сервер OpenSSH с оболочкой Git передаёт `$SHELL`.
- `DefaultShell` = `sh.exe` Git меняет оболочку всех входов по SSH на этот компьютер.
- У администратора ключ Kit в `administrators_authorized_keys` открывает вход любого
  администратора компьютера, но только с 127.0.0.1 и ::1.
- Вид карточки в живой панели на Windows: модель покрыта тестами, DOM — нет.
