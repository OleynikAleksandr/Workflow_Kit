# Кластер: workflow-engine / session-loop

## Назначение

Цикл сессии агента без собственного чата (спецификация вехи 2, разделы
9–11): канал к агенту через хуки `Stop` и `UserPromptSubmit`, автопилот,
переключатель «Ревью плана» и перекрёстное ревью, имена сессий.

## Модули

| Модуль | Обязанность |
| --- | --- |
| [agent-channel](modules/agent-channel/module.md) | приём хуков `Stop`/`UserPromptSubmit`, очередь сообщений агенту с однократной доставкой, удержание `Stop` до решения пользователя (до 9 минут), активность сессий |
| [autopilot](modules/autopilot/module.md) | решение «продолжать, держать или отпустить» после хода и действия с планом из панели |
| [cross-review](modules/cross-review/module.md) | перекрёстное ревью плана сессией другого провайдера: запуск ревьюера, пересылка ходов, согласие или 5 кругов (M4) |
| [plan-review](modules/plan-review/module.md) | переключатель «Ревью плана» сессии: хранение и видимость до выбора пути (самой функции ревью в вехе 2 нет) |
| [session-titles](modules/session-titles/module.md) | имена сессий: ручное, тема агента, цель плана, имя провайдера; синхронизация с ChatGPT; архив сессий |

## Границы

- Сообщения агенту идут только через `agent-channel` (`enqueue`);
  решение по `Stop` даёт автопилот через `setDecider`.
- Хуки принимаются только с loopback; служба недоступна — агент работает
  как обычно (`wfk hook` выходит с кодом 0 без вывода).
