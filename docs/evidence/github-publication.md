## T001 — документы и состав файлов

Подготовлены README для нового пользователя, подробная инструкция
[установки](../installation.md), корневой [CHANGELOG](../../CHANGELOG.md)
и уточнения архитектурного обзора. CHANGELOG использует даты коммитов
выпуска и документы приёмки, не добавляет неподтверждённый релиз 0.2.0.
Версия приложения не повышалась.

### Проверки документов

- Четыре пользовательских/архитектурных Markdown-документа прочитаны в UTF-8;
  символов замены и незакрытых блоков кода нет.
- Проверены 83 относительные ссылки, включая используемые якоря: ошибок нет.
- `git diff --check`: без ошибок.
- Платформенные ограничения сверены с кодом и контрактом установщика:
  Windows-провайдеры отключены; Linux/Windows проверены только подставными
  системными командами, не установкой на устройствах.
- `npm ci` описан как подготовка разработки и тестов, а не обязательный
  шаг установки работающего приложения.

### Состав и правила Git

До изменений T001 отслеживалось 317 файлов. В перечне присутствуют
`bin/wfk.mjs`, исходники, ресурсы панели и архив бандла Kit, необходимый
для подготовки управляемых проектов. Они не исключаются из Git.

Добавлены общие правила для `docs/start/`, `.workflow-kit/local/`, локальных
настроек Claude, временных файлов, покрытия, журналов и локальных секретов.
Раньше `docs/start/` исключался только через `.git/info/exclude` этого клона.
Проверка `git check-ignore --no-index` подтверждает:

- README, CHANGELOG, руководство, архитектурный обзор, package.json,
  запускатель и поставляемый архив Kit не игнорируются;
- примеры локальных путей `docs/start/README.md`, `.workflow-kit/local/test.json`,
  `.env`, `.env.local`, `tmp/test`, `coverage/test`, `local.key` игнорируются.

`git ls-files -ci --exclude-standard` не обнаружил уже отслеживаемых файлов,
которые новые правила сделали бы игнорируемыми. Управляемый блок Kit
в `.gitignore` не изменён; новые правила добавлены за его пределами.

### Проверка истории перед публикацией

На базе `683411a` проверены имена объектов истории и 1355 текстовых версий
файлов самого проекта (22 384 187 байт). Поиск характерных шаблонов приватных
ключей, GitHub/OpenAI/AWS-токенов и URL с паролями совпадений не нашёл.
Это ограниченная проверка шаблонов, а не доказательство отсутствия любых
секретов. Содержимое Kit internals, поставляемого бандла, бинарных ресурсов,
журналов и JSONL исключено; зависимости не входят в итоговую проверку
текстов самого проекта. В текущем списке JSONL — два тестовых fixture-файла
провайдера Claude, а не пользовательские транскрипты.

В ранней истории обнаружено 289 путей внутри `node_modules`, включая
каталоги: ранее были закоммичены зависимости разработки. В текущем дереве
отслеживаемых зависимостей нет. Публикация существующей истории сохранит
эти старые объекты; `.gitignore` не удаляет прошлые коммиты. История
не переписывалась. Путей `docs/start/` в проверенной истории не найдено.
Новая лицензия не выбиралась и не добавлялась; происхождение поставляемого
бандла зафиксировано в его существующем PROVENANCE.

## Публикация — ожидает T002

При подготовке scope GitHub подтвердил публичный репозиторий, права push
и наличие ветки main. Чтение README через API вернуло 404; это не доказывает,
что удалённая ветка пуста. На момент начала scope локальных remote не было.

Настройка origin, сверка и сохранение удалённой истории, проверка запуска
из временной копии, push и проверка SHA на GitHub выполняются в T002.
Публикация этим документом пока не подтверждается. Установленная служба
пользователя в T001 не переустанавливалась и не перезапускалась.
