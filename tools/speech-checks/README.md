# Проверки из связанного рабочего дерева

`node tools/speech-checks/test.mjs` запускает ровно обе существующие группы
`test:app` и `test:kit` с прежней конкурентностью 4, без исключений тестов.
Перед запуском удаляются переменные GIT_* и HARNESS_WORKFLOW_ROOT, унаследованные
от pre-commit. Тесты создают собственные временные репозитории; hook другого
репозитория не должен передавать им GIT_DIR/GIT_INDEX_FILE/GIT_WORK_TREE.
См. https://git-scm.com/docs/githooks (работа с foreign repository).

Поведение одинаково на macOS, Linux и Windows: process.execPath запускается
напрямую с массивом аргументов; npm.cmd и оболочка не требуются.
Коды ошибок дочернего процесса передаются без изменения. Тесты не пропускаются.
