# Часть продукта: control-panel

## Назначение

Веб-панель Workflow Kit для Mac и iPad: статические HTML/CSS/ES-модули без
сборки (D3), опрос `GET /api/state` раз в 3 с. Вид — по согласованному
макету `docs/design/ui-mockup.html` (веха 2): боковая панель с деревом
«проект → сессии» и экран справа, служебные сведения в «Настройках»;
светлая и тёмная тема (как в системе или по выбору), системный шрифт,
экран «Домой» iPad (manifest, значки, standalone).

## Кластеры

| Кластер | Назначение |
| --- | --- |
| [web-panel](clusters/web-panel/cluster.md) | раскладка, дерево проектов и сессий, экраны (в том числе диалог сессии, M18), «Настройки» со служебными карточками |

## Границы

- Только отображение и вызовы HTTP API; бизнес-логики и доступа к диску нет.
- Файлы отдаёт сервер модуля `http-server` из каталогов `src/` модулей
  панели; отдаются только типы `.html`, `.js`, `.css`, `.webmanifest` и
  изображения.
- JS проверяется `tsc` через JSDoc и `// @ts-check`.
- Текст вставляется только через `textContent`, без `innerHTML` с данными.
