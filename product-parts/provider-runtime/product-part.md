# Часть продукта: provider-runtime

## Назначение

Работа с провайдерами (Claude, Codex) через общий контракт: реестр
провайдеров, журнал хука SessionStart, маршруты провайдеров, запуск и учёт
процессов сессий и окружений. Контракт и проверенные факты о провайдерах —
`docs/planning/M1-providers.md`.

## Кластеры

| Кластер | Назначение |
| --- | --- |
| [provider-contract](clusters/provider-contract/cluster.md) | контракт провайдера, реестр, журнал хука, процессы (D5, D9) |
| [provider-adapters](clusters/provider-adapters/cluster.md) | реализации контракта для Claude и Codex |

## Границы

- Пишет в чужие конфиги только по кнопке, после предпросмотра с токеном (D7).
- Регистрирует свои маршруты и раздел состояния в реестрах `http-api`;
  собственного HTTP-сервера не имеет.
- Не знает о вёрстке панели: карточки провайдеров строятся в
  `control-panel` из данных контракта.
- Код модулей появляется в задачах T004–T007; в T001 создан только скелет.
