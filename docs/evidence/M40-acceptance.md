## Найдено при проверке

- Текст продолжения запуска для задачи delivery (служба `decide-orchestration.ts`, Kit
  `autopilot-decision.ts`) по-прежнему называет `task:start <ID> --autopilot-run <run>`, хотя в
  режиме `host` флаг не нужен (спецификация, раздел 2.1). Kit стартует задачу и без флага —
  сценарий 1 выполняет `task:start D1` без флагов. Противоречие текста; исправление — раунд
  исправлений или M41 (противоречия текстов).
- Повторное нажатие кнопки приёмки без идентификатора запроса Kit (карточка нарисована до
  появления запроса) отклоняется Kit как `NOT_READY`, а не возвращает `already: true`; второй
  записи нет.

## Не проверено

- HTTP-маршруты службы и команда `wfk` в сквозных сценариях не вызываются (их проверяют тесты
  модуля `cli`); панель в браузере в этих сценариях не открывалась, карточки T008 проверены
  тестами модели и разметки, визуально — нет.
- Потерянный ответ Kit и перезапуск службы с записью `issued` — только модульные тесты T005
  (`decisions.test.ts`, `decisions-real.test.ts`), не сквозные.
- Провайдеры Claude, Codex и Kimi вживую не запускались; настоящий GitHub CI — задача T011.
- Linux и Windows: сквозные сценарии запускаются в CI четырёх платформ (T011); здесь — только macOS.
