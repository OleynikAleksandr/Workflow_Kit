# Кластер: provider-runtime / provider-contract

## Назначение

Общий контракт провайдера и всё, что не зависит от конкретного провайдера:
реестр провайдеров, журнал хука SessionStart, маршруты провайдеров, запуск,
учёт и остановка процессов (D5, D9).

## Модули

| Модуль | Обязанность | Задача |
| --- | --- | --- |
| `provider-registry` | контракт, реестр провайдеров, журнал хука, маршруты провайдеров | T004 |
| `process-supervisor` | запуск, учёт и остановка процессов по своим записям | T004 |

Модули ещё не созданы; их контракты появятся вместе с кодом.

## Границы

- Процессы останавливаются только по своим записям (pid, время старта,
  командная строка, boot id); никаких `pkill` по шаблону.
- Долгие действия — операции с `operationId` (D10).
- Не содержит знаний о Claude или Codex: они в `provider-adapters`.
