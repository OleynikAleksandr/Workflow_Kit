# M28: факты для исправлений контролов Claude

Исследование к [спецификации M28](../planning/M28-claude-controls-fixes.md). Проверенное
помечено **[проверено]**, остальное **[не проверено]**; разделы с пометкой «заполняет
T001» дополняются в T001.

## 1. Окно контекста и порог автосжатия

- **[проверено]** Claude Code 2.1.325 собирает `context_window` для statusline из окна
  модели: `context_window_size` — окно модели (`opus[1m]` → 1 000 000),
  `used_percentage = round((input + cache_creation + cache_read) / окно × 100)`,
  `total_input_tokens` — токены текущего контекста.
- **[проверено]** `autoCompactWindow` (общий и `modelSettings[<модель>].autoCompactWindow`)
  в данные statusline не входит; его учитывают `/context` и панель Context приложения
  Claude (`maxTokens`, `rawMaxTokens`, `autocompactSource`).
- **[проверено]** В коде 2.1.325 есть переменная `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, поиск
  порога по слоям настроек от старшего к младшему, предпочтение точного id модели, значение
  `"auto"` и пороги организации с сервера (кэш `autoCompactWindowsCache`).
- **[не проверено]** Приоритет переменной окружения над настройками и пути managed на
  трёх ОС — заполняет T001.

## 2. Кадры экрана 2.1.325 (заполняет T001)

- **[проверено]** Во время активного хода хост Kit держал `interrupt-state` = `idle`,
  `epoch` = `:0`; признак работы `esc to interrupt` на экране не находился.
- Кадры «работа», «свободен», «диалог разрешения», «после Esc» и их признаки — T001.

## 3. Хуки и транзакции параметров (заполняет T001)

- **[проверено]** Пока транзакция параметров в `control`, `nativeControlHook` возвращает
  `true` для любого prompt- и stop-хука сессии; канал этот хук не получает.
- **[проверено]** Пока движок `busy`, цикл хоста пропускает `.text`, `.message`, `.rename`.
- Порождает ли slash-команда движка prompt- и Stop-хуки — T001.

## 4. Esc в диалоге разрешения (заполняет T001)

- Останавливает ли одно Esc ход в диалоге разрешения и какая метка остаётся в
  транскрипте (`[Request interrupted by user]` или вариант `for tool use`) — T001.

## 5. Воспроизведение потери доставки (заполняет T001)

- Сценарий: транзакция параметров во время хода → проглоченный Stop → сообщение панели
  «В очереди…» → доставка только хуком следующего сообщения — T001.

## 6. Бюджет живых ходов

Не больше 6 коротких ходов на самой дешёвой модели каталога, в своём временном проекте
Kit с очисткой: T001 — до 3, T007 — до 3 (T008 — только остаток T007).
