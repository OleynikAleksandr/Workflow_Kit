# M33: вопросы агента — карточка в панели

Продолжение [спецификации M33](M33-agent-questions.md): раздел 2.5 вынесен сюда без изменений,
чтобы спецификация оставалась в пределе 28 000 байт. Общий контракт — 2.1, провайдеры — в
[решении по провайдерам](M33-agent-questions-providers.md).

## 2. Решение (продолжение)

### 2.5. Панель: карточка вопроса (`session-chat`)

Новые `src/question-model.js` (чистая модель) и `src/question-card.js`; стили — в
`session-chat.css`. Эталон — карточка Claude Desktop (снимок пользователя 15.11.2026, тёмная
тема) в токенах панели.

- Ожидающий вопрос стоит в конце ленты над полем ввода; закрытый — в ленте после
  `afterMessageId`, компактно: вопрос и выбранный ответ, «Ответ дан в приложении» или
  «Вопрос отменён».
- Часть: заголовок-метка, текст вопроса, варианты (подпись и описание) — радиокнопки или
  флажки при `multiSelect`; при `allowOther` — строка «Свой вариант» с полем текста.
  Несколько частей идут одна под другой в одной карточке.
- «Отправить» активна, когда выбран ответ на каждую часть; с клавиатуры — Ctrl/⌘+Enter.
  Одно нажатие по варианту ответ не отправляет. Кнопки «Пропустить» в M33 нет (раздел 5).
- `answerable: false`: варианты видны без выбора, под ними причина и ссылка на чат провайдера.
- Выбор хранится вместе с состоянием сессии и переживает опрос. Вопрос закрылся, пока
  пользователь выбирал, — карточка показывает итог; `question-stale` — то же и внеочередной
  опрос.
- Попытка: карточка создаёт `attemptId` при нажатии «Отправить» и повторяет запрос с тем же
  `attemptId` при сетевой ошибке. Отказы, при которых ничего не передано (`question-invalid`,
  `question-unavailable`, `question-failed`), — текст ошибки под карточкой, выбор сохранён,
  новая попытка той же кнопкой. После `question-timeout`, `question-sent` и при
  `delivery: 'sent'` кнопки нет: «Ответ отправлен, ждём подтверждения», итог приходит опросом.
- Исход `unknown` и закрытие без `answers`: «Ответ отправлен. Какой ответ принят, провайдер
  не сообщил» или «Ответ дан в приложении» — без подстановки выбора панели.
- Сенсорные цели не меньше 44 px, без элементов, видимых только при наведении; тёмная и
  светлая темы; узкая раскладка iPad.
- Пока есть ожидающий вопрос, строка состояния диалога — «Агент ждёт вашего ответа».
